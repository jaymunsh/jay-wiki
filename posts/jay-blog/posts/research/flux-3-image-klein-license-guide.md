> **이 글의 대상**: 이미지 생성 모델을 직접 띄워 서비스에 붙이려는 개발자와, 그 결과물을 상업적으로 써도 되는지 판단해야 하는 사람. 특히 FLUX.2 Klein 4B의 Apache 2.0을 기억하고 "Klein이면 자유롭게 쓸 수 있다"고 생각하는 사람.

> **출처 및 기준일**: 1차 출처는 [Hugging Face 모델 카드](https://huggingface.co/black-forest-labs/flux-3-image-klein)와 같은 저장소의 [LICENSE.md](https://huggingface.co/black-forest-labs/flux-3-image-klein/blob/main/LICENSE.md)다. 가격·성능 수치와 경쟁 모델 비교는 [VentureBeat의 10월 15일 기사](https://venturebeat.com/technology/black-forest-labs-opens-flux-3-image-klein-weights-with-free-commercial-use-limited-to-smaller-businesses)를 참고했다. 판정 기준일은 10월 15일이다. **이 글은 라이선스 조항을 정리한 것이고 법률 자문이 아니다.** 실제 도입 전에는 원문 전체를 읽고, 필요하면 Black Forest Labs에 직접 확인한다.

## 1. 같은 Klein이라는 이름 아래 라이선스가 세 번 바뀌었다

"Klein"은 Black Forest Labs가 작고 빠른 모델에 붙이는 이름이다. 문제는 세대마다 라이선스가 다르다는 점이다.

| 모델 | 크기 | 라이선스 | 상업적 사용 |
|---|---|---|---|
| FLUX.2 [klein] 4B | 4B | Apache 2.0 | 자유 |
| FLUX.2 [klein] 9B | 9B | 비상업 라이선스 | 불가 |
| **FLUX 3 Image Klein** | **5.6B** | **FLUX Kommunity License 1.0** | **연매출 500만 달러 미만만, 조건부** |

4B를 쓰던 팀이 "같은 Klein의 새 버전"이라고 생각하고 그대로 바꾸면, Apache 2.0에서 조건부 라이선스로 넘어가게 된다. 이 글의 대부분을 라이선스에 쓰는 이유다.

## 2. 모델 자체는 로컬 구동에 맞춰 나왔다

| 항목 | 내용 |
|---|---|
| 크기 | 이미지 트랜스포머 5.6B. 텍스트 인코더는 별도(Qwen3-VL-4B-Instruct, Apache 2.0) |
| 변형 | Base(증류 전, 50스텝, 파인튜닝용), 증류판(16스텝, 생성·편집용, API와 같은 체크포인트), FP8·NVFP4, 그리고 기사 기준 INT8 |
| 기능 | 텍스트→이미지, 단일 참조 편집, 최대 10장의 다중 참조 생성, 0~1000 좌표 바운딩 박스로 배치·교체·제거 |
| 상위 모델에서 이어받은 것 | 4K 출력, 공간 제어, 8GB VRAM 소비자 GPU 구동 (BFL 주장) |
| 지원 도구 | ComfyUI, Diffusers, Ostris AI Toolkit, vLLM-Omni, SGLang Diffusion, NeMo AutoModel |

모델 카드에 적힌 주의점도 있다. 바운딩 박스는 픽셀을 강제하는 마스크가 아니다. 글자 렌더링은 부정확할 수 있다. 짧은 프롬프트는 평범한 결과를 내므로 프롬프트 업샘플러가 필요하다.

하드웨어 수치는 두 출처가 다르다. "8GB로 돈다"는 것은 BFL의 주장이고, BFL은 8GB 최소 구성과 4K 출력을 직접 시험하지 않았다. 모델 카드에 적힌 B200 기준 1024×1024 최대 메모리는 BF16에서 31GB, FP8에서 26GB, NVFP4에서 25GB다. 프롬프트 업샘플러를 켜면 약 28GB가 더 든다.

| 환경 (기사 기준) | 1024² 생성 / 편집 | 2048² 생성 / 편집 |
|---|---|---|
| RTX 5090, INT8, 16스텝 | 4.1초 / 7.2초 | 15초 / 43초 |
| RTX 5090, Base 50스텝 | 12.5초 / 27.4초 | 79.8초 / 236초 |
| RTX 4070, INT8, 16스텝 | 8.9초 / 18.9초 | 50.4초 / 150초 |

## 3. API로 쓰면 1K 한 장에 1센트가 안 된다

| 해상도 | Klein API | 비교 |
|---|---|---|
| 768×768 | $0.008 | |
| 1K | $0.009 | FLUX 3 Image $0.048, Krea 3 $0.03, Nano Banana 2.1 $0.0336 |
| 2K | $0.014 | Krea 3 $0.06, Nano Banana 2.1 $0.0504 |
| 4K | $0.036 | Nano Banana 2.1 $0.113 |

생성과 편집이 같은 가격이다. **API를 쓰면 라이선스의 매출 기준과 무관하게 상업적으로 쓸 수 있다.** 연매출 500만 달러를 넘는 조직에게는 API가 가장 단순한 길이다. 다만 API의 증류판에는 BFL의 프롬프트 처리 파이프라인이 붙어 있어서, 같은 체크포인트를 로컬에서 돌린 결과와 다를 수 있다.

성능 비교는 BFL 자체 평가뿐이다. 프롬프트, 판정 방식, 표본 수가 공개되지 않았고, 비교 차트에 GPT Image 2.5와 Nano Banana 2.1이 빠져 있다. "공개 가중치 모델 중 앞선다"는 주장까지만 읽는 것이 맞다.

## 4. 라이선스의 첫 관문은 '나와 계열사를 합친 연매출'이다

FLUX Kommunity License 1.0은 11개 절로 되어 있다. 상업적 사용 여부는 §1.e의 정의 한 줄에서 갈린다.

> "Qualifying User" means you, if at any time you together with your affiliates' gross annualized revenue is less than US$5,000,000.

이 문장에서 읽어야 할 것은 세 가지다.

| 문구 | 의미 |
|---|---|
| together with your affiliates | 내 회사만이 아니라 계열사 매출을 합친다. 작은 자회사라도 큰 그룹에 속하면 해당하지 않는다 |
| gross annualized revenue | 이익이 아니라 총매출이다. 계산 방식과 "계열사"의 정의는 라이선스에 없다 |
| at any time | 판정은 한 번으로 끝나지 않는다. 매출이 기준을 넘으면 그때부터 자격이 없다 |

기준을 넘었을 때의 유예 기간이나 통보 의무는 따로 없다. §2.b는 그 밖의 상업적 사용에 대해 "Company에 라이선스를 요청해야 한다"고 적고, 그때 수수료나 매출 분배를 요구할 수 있다고 둔다.

## 5. 자격이 있어도 '출력물'과 '모델'은 따로 다룬다

이 라이선스에서 가장 중요한 구분이다. 상업적 예외는 **출력물을 상업적으로 쓰는 것**에만 열려 있다.

| 하려는 일 | 연매출 500만 달러 미만 | 그 이상 |
|---|---|---|
| 생성한 이미지를 상업적으로 쓴다 | 가능 (§2.a(ii)). 아래 필터·검토 조건이 붙는다 | 별도 라이선스 또는 API |
| 모델로 돈 버는 서비스를 운영한다 | 출력물 사용 범위로 볼 수 있는지 원문 확인 필요. §1.c는 "수익을 내는 활동(운영 환경 포함)"을 비상업 목적에서 뺀다 | 별도 라이선스 또는 API |
| 파인튜닝·LoRA를 만든다 | 파생물(Derivative)이 된다. 원 모델의 제한이 그대로 따라간다 | 같음 |
| 파인튜닝한 모델을 배포한다 | **비상업 목적으로만** (§2.a, §3) | 같음 |
| 원본 가중치를 재배포한다 | 비상업 목적으로만, 라이선스 사본과 고지문을 함께 | 같음 |
| 출력물로 다른 이미지 모델을 학습시킨다 | **금지** (§4.b) | 금지 |

모델 카드도 같은 점을 짚는다. 상업적 예외는 "상업적 파인튜닝이나 배포에 대한 포괄적 허가가 아니다."

### 파생물의 범위가 넓다

§1.a의 파생물 정의에는 파인튜닝한 모델과 증류로 만든 모델이 모두 들어간다. 더 나아가 FLUX의 출력물로 학습해 FLUX의 동작을 흉내 내는 모델도 파생물로 분류한다(§1.a(iii)). 그리고 §4.b는 FLUX 모델, 파생물, 출력물을 써서 "FLUX와 비슷한 기능을 하는 다른 AI 모델을 개선하는 것"을 금지한다. Klein으로 만든 이미지를 다른 이미지 모델의 학습 데이터로 쓰는 계획이라면 이 조항부터 확인해야 한다.

### 상업적 출력물에는 운영 의무가 붙는다

§2.e는 상업적으로 쓰는 Qualifying User에게 둘 중 하나를 요구한다.

1. 콘텐츠 필터링 장치를 구현하고 유지한다
2. 출력물을 배포하기 전에 불법·침해 콘텐츠인지 검토한다

여기에 더해, 관련 법이 요구하는 범위에서 출력물에 AI 생성 표시를 넣어야 한다. "무료로 상업적 사용 가능"이라는 요약에는 이 의무가 빠져 있다.

### 배포할 때는 고지문을 붙인다

모델이나 파생물을 배포할 때는 다음 문장을 눈에 띄게 표시해야 한다(§3.b).

> This FLUX Model is licensed by Black Forest Labs Inc. under the FLUX Kommunity License.

파생물이라면 원 모델을 수정했다는 문장도 덧붙인다(§3.c). 하위 라이선스 부여는 금지다.

## 6. 금지 용도와 종료 조건도 짧게 확인한다

§4가 금지하는 용도는 군사 목적, 감시와 그 연구개발, 생체 정보 처리, 불법 콘텐츠(CSAM, 비동의 친밀 이미지 포함), 퍼블리시티권·디지털 복제권 같은 제3자 권리 침해 등이다.

종료 조건은 세 가지다(§8).

- 위반하면 자동으로 종료된다.
- BFL은 통지만으로 언제든 라이선스 전부나 일부를 종료할 수 있다.
- 모델과 관련된 지식재산권 소송을 제기하면 자동으로 종료된다.

종료되면 모델과 파생물의 사용·배포를 모두 멈춰야 한다. 두 번째 조건 때문에, 이 라이선스는 Apache 2.0처럼 "한 번 받으면 계속 쓸 수 있는" 권리가 아니다.

## 7. 정리: 작은 팀의 이미지 생성에는 열렸고, 모델을 다루는 일에는 닫혀 있다

| 이런 경우라면 | 판단 |
|---|---|
| 연매출 500만 달러 미만 팀이 마케팅 이미지를 만든다 | 쓸 수 있다. 필터 또는 검토 절차와 AI 표시를 갖춘다 |
| 자사 스타일 LoRA를 만들어 내부에서 쓴다 | 파생물이다. 출력물의 상업적 사용은 자격 안에서 가능하지만, LoRA 자체를 판매·배포하는 것은 안 된다 |
| 큰 그룹의 계열사다 | 계열사 매출을 합친다. API를 쓰거나 별도 라이선스를 받는다 |
| 출력물로 자체 이미지 모델을 학습시킨다 | 금지 조항에 걸린다 |
| 제약 없는 오픈 모델이 필요하다 | 이전 세대 FLUX.2 Klein 4B(Apache 2.0)나 다른 Apache 모델을 본다 |

가중치를 공개한 것은 분명히 반가운 일이다. 하지만 "open weights"와 "오픈소스 라이선스"는 다르다. Klein은 앞의 것이고, 뒤의 것은 아니다.

### 이 글에서 확인하지 못한 것

- 커뮤니티 반응: 공개 당일 기준으로 라이선스 변화를 다룬 커뮤니티 논의는 찾지 못했다. 검색 결과 대부분이 아직 FLUX.2 Klein을 다루고 있었다.
- "계열사"와 "총매출"의 정확한 정의: 라이선스 본문에 없다.
- 성능: 독립 벤치마크가 아직 없다. 모든 비교 수치는 BFL 또는 기사가 읽은 차트 값이다.

## 10월 22일 수정: 경쟁 오픈 모델과의 비교

발행 다음 날 [OrcaRouter](https://www.orcarouter.ai/blog/flux-3-image-klein-vs-qwen-image-2-1-turbo)가 일주일 먼저 나온 Qwen-Image 2.1 Turbo와 비교한 글을 냈다. 여기에 기존 Apache 모델 둘을 더해 정리했다.

| | FLUX 3 Image Klein | Qwen-Image 2.1 Turbo | Z-Image Turbo | FLUX.2 Klein 4B |
|---|---|---|---|---|
| 라이선스 | FLUX Kommunity (연매출 500만 달러 미만 상업 허용) | Qwen Research (상업은 별도 계약) | Apache 2.0 | Apache 2.0 |
| 크기 | 5.6B + 별도 텍스트 인코더 4B | 7B | 확인 못 함 | 4B |
| 스텝 | 16 (증류판) | 8 | 증류판 | 증류판 |
| 최대 출력 | 4K | 2752×1536 | 확인 못 함 | 확인 못 함 |
| API 가격 (1K 한 장) | $0.009 | $0.016 (해상도 무관) | 없음 | 없음 |
| BF16 내려받기 크기 | 약 20.3GB | 약 32.4GB | 확인 못 함 | 확인 못 함 |

- **이 비교에서는 라이선스가 성능보다 먼저 결정한다.** Qwen-Image 2.1은 이전 세대의 Apache 2.0에서 연구·평가 전용으로 바뀌었다. 그래서 작은 회사가 협상 없이 상업에 쓸 수 있는 쪽은 Klein이다. 제약이 아예 없어야 하면 Z-Image Turbo나 FLUX.2 Klein 4B로 간다.
- **Klein에는 숨은 비용이 있다.** 프롬프트를 늘려 주는 9B 업샘플러가 필요하고, 80GB 카드에서 약 28GB를 더 쓴다. 투명 배경(RGBA)과 마스크 기반 편집은 Qwen 쪽만 지원한다.
- **가격은 2K까지 Klein이 싸다.** 1만 장 기준 1K에서 $90 대 $160, 2K에서 $140 대 $160이다. 4K에서는 Klein만 가능하고 $360이다.
- **품질 비교는 아직 없다.** 두 모델 모두 Artificial Analysis 독립 점수가 없다. Klein이 FLUX.2 Klein 9B보다 70 Elo 높다는 주장도 BFL 자체 차트뿐이다.

### 커뮤니티 반응

FLUX 3 Klein을 직접 다룬 커뮤니티 후기는 여전히 찾지 못했다. 앞 세대 FLUX.2 Klein에 대한 ComfyUI 사용자 비교는 있다. 인물 사진은 Z-Image Turbo가 더 다듬어졌고, 조명 방향을 따르는 능력과 구도 일관성은 Klein이 낫다는 평이다([criticatv 비교](https://www.criticatv.com/z-image-vs-flux-klein-vs-qwen-image-krea-2-comfyui/)). 증류 모델은 CFG 1.0으로 학습돼서, 값을 올리면 색이 과포화되고 피부가 플라스틱처럼 보인다는 주의도 함께 나왔다.
