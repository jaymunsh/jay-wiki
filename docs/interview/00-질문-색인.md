# 00. 질문 색인 — 이 질문이 오면 어디를 보나

작성: 2026-09-03
용도: **면접 직전에 이것만 훑는다.** 나머지 다섯 파일은 6,800줄이라 그때 읽을 수 없다.

각 행은 「실제로 나올 법한 질문 → 어디를 펼치나 → 첫 문장」이다.
**첫 문장은 답 전체가 아니라 입구다.** 그 문장을 뱉고 나면 해당 편의 2번 칸(원리)이 뒤를 받친다.

---

## 0. 먼저 외울 것 — 진위 지도

**면접에서 가장 위험한 순간은 대본을 실행처럼 말하다 들키는 것이다.** 그러면 진짜 9편까지 의심받는다.
그래서 이것부터 외운다.

| | 편수 | 무엇 |
|---|---|---|
| **A군 — 실제로 돈다** | **9편** | Saga · Kafka DLQ · 채팅 대기열 · 검색 비교 · 제휴 API · **데이터 소유권** · HPA · 백업 복원 · **알림 사슬** |
| **B군 — 정의된 흐름** | 14편 | 나머지 전부. 화면은 실행되지만 **단계와 숫자가 미리 적혀 있다** |

> **B군을 말할 때는 내가 먼저 「이건 설계 정리입니다」라고 말한다.** 그게 오히려 강한 답변이다.
> 기준은 하나다 — **숫자를 주장하는가.** "재고 갱신을 한 트랜잭션으로 직렬화했다"는 설계 주장이라 괜찮고,
> "600 RPS, p95 380ms"는 측정값 형태인데 상수라 "어떻게 측정하셨어요?" 한 마디에 무너진다.

| **A. 안 돌려 본 것은 없는 것이다** | 스크립트가 있는 것과 기능이 있는 것은 다르다 | 롤백을 뜨지 않는 이미지로 태웠다 — 9초, 66회 200 |
| **B. 고치려다 더 깨뜨렸다** | 되돌릴 수 없는 조작은 되돌릴 수 있게 만들고 나서 한다 | SIGHUP 하나가 공개 hostname 과 SSH 복구 경로까지 끊었다 |
| **C. 조용히 틀리고 있었다** | 실패하는 자동화보다 **성공하면서 범위가 줄어든** 자동화가 위험하다 | 백업은 매일 성공하는데 대상만 줄고 있었다 |
| **D. 믿음을 실측으로 바꿨다** | "필요 없습니다"는 확인할 방법이 없을 때 하는 말이었다 | 파드를 둘로 만들고 나서야 세션이 이미 Redis 에 있던 걸 알았다 |
