# 비공개 운영 자료 안내

이 문서의 상세 운영 기록은 별도 운영 저장소 `jay-wiki-ops-private`의 동일 상대 경로에 보존했다.
애플리케이션 실행에 필요한 파일이 아니며, 기존 문서 링크를 유지하기 위해 이 안내를 남긴다.

공개 가능한 구조와 절차는 저장소의 `docs/deploy-runbook.md`와
`docs/deployment-security-boundary.md`에서 확인한다. 실제 자격증명은 Git에 보관하지 않는다.

주의: 현재 파일을 대체해도 과거 Git 이력의 원문은 삭제되지 않는다.
현재 공개 저장소의 배포 경계는 `docs/deploy-runbook.md`를 따른다.
