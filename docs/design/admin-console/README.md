# 관리자 외관 시안 — A안 확정

2026-09-11 사용자가 **A안(운영 콘솔)**을 선택했다. 실제 구현의 계약은 [관리자 분리 워크북](../../workbooks/admin-subdomain-separation.md)의 0절 및 4.1~4.4절을 따른다. 다크모드는 필수이며 시안의 토글만으로 완성됐다고 판단하지 않는다.

- [A안 기준 캡처](concept-a.png): 라이트 모드, 샘플 문서/수치.
- [비교 HTML](index.html), [스타일](style.css), [샘플 동작](app.js).
- B/C는 비교 이력이다. B의 분할 편집이나 C의 카드 목록을 A에 임의로 섞지 않는다.
- 상단 시안 선택 막대와 컨셉 안내, 가상 `review` 상태/수치/작업 기록은 제품에 넣지 않는다.
- 시안은 독립 HTML이다. CSS 전역 규칙, 9~10px 글자, `body.dark`를 Next 앱에 그대로 복사하지 않는다. 실제 구현은 기존 토큰/11px 하한/`html[data-theme]`를 따른다.

저장소 루트에서 다시 보기:

```bash
# 먼저 4321번 포트가 이미 사용 중인지 확인한다.
lsof -nP -iTCP:4321 -sTCP:LISTEN
# 사용 중인 시안 서버가 없다면 실행한다.
python3 -m http.server 4321 --bind 127.0.0.1 --directory docs/design/admin-console
```

브라우저에서 `http://127.0.0.1:4321/#a`를 연다. 이 서버는 디자인 자료만 제공하며 API/DB에 연결하지 않는다. 실제 관리자 목표 주소인 `admin.localhost:3000`과 다르다.

시안 단계에서는 3개 컨셉의 데스크톱·모바일 문서 넘침, 샘플 검색·필터·미리보기 동작을 확인했다. 이 결과는 관리자 인증, 실제 데이터 CRUD, 제품 다크모드 대비의 검증 결과가 아니다. 다음 단계는 시안 도구 기능 확장이 아니라, 별도 구현 요청을 받은 뒤 워크북의 인증 계약과 A안 적용을 진행하는 것이다.
