데이터 흐름과 화면 이용 안내

1. 실행 폴더를 읽는 카탈로그 빌더

node scripts/build-site-catalog.mjs를 실행하면 runs/<model-slug>/<run-id>/의 기록을 스캔해 benchmark-html/data/catalog.json을 갱신합니다. 폴더 추가만으로 화면이 바뀌는 것은 아니며 빌더 실행이 필요합니다.

2. HTML 실행과 보고서 원문을 분리해서 확인

화면 안 미리보기로 빠르게 확인하거나 새 탭에서 원본을 직접 조작할 수 있습니다. RESULT.md는 제출자가 작성한 보고서이므로 최종 평가표와 동일한 의미가 아닙니다.

3. 정적 HTTP 환경 권장

백엔드 없이 동작하지만 file://로 직접 열면 브라우저 보안 정책 때문에 JSON과 Markdown 로딩이 제한될 수 있습니다. 로컬 HTTP 서버나 정적 호스팅에서 확인하는 편이 안전합니다.
