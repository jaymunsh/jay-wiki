개인 AI 작업 기록 도구

여러 모델의 작업을 한곳에 기록하고 비교하세요.

Leneu Desk는 AI 작업 기록, 결과 비교, Markdown 내보내기를 제공합니다. 여러 모델을 비교하는 개인 개발자를 위해 만들어졌습니다.

무료로 시작하기 기능 알아보기

주요 기능

작업을 기록하고, 결과를 나란히 비교하고, 필요한 곳에서 Markdown으로 꺼내세요.

작업 기록

모델별로 요청과 결과를 자동으로 묶어 저장합니다. 검색하고 되돌릴 수 있습니다.

결과 비교

여러 모델의 출력을 나란히 대조하고 차이점을 한눈에 확인합니다.

Markdown 내보내기

기록한 내용을 Markdown 파일로 내보내 문서나 노트로 바로 사용합니다.

사용 흐름

세 단계로 시작합니다.

STEP 01

시작

신청 폼을 채우고 무료 계정을 만듭니다.

STEP 02

기록·비교

모델 작업을 기록하고 결과를 비교합니다.

STEP 03

내보내기

Markdown으로 정리해 작업물을 공유합니다.

가격

무료로 시작하고 프로젝트가 늘면 Plus로 확장하세요.

무료

개인적으로 여러 모델을 살짝 비교할 때.

0원 / 월
  • 프로젝트 3개
  • 작업 기록·비교
  • Markdown 내보내기
무료로 시작

Plus

무제한 프로젝트가 필요한 개발자를 위해.

9,000원 / 월
  • 무제한 프로젝트
  • 모든 기록 저장
  • 우선 내보내기
Plus 시작

자주 묻는 질문

질문을 클릭하면 답변이 열립니다.

무료 플랜은 3개의 프로젝트까지 만들 수 있습니다. 그 이상은 Plus로 확장됩니다.
Plus는 월 결제 9,000원 또는 연 결제 90,000원으로 이용 가능합니다. 단위를 바꾸면 금액과 결제 단위 함께 변경됩니다.
Markdown 형식으로 내보낼 수 있습니다. 문서나 노트에 바로 붙여 사용할 수 있습니다.
신청 폼을 완료하면 바로 계정을 사용할 수 있습니다. 실제 결제 처리는 별도의 절차가 아닙니다.

신청

이메일을 남겨 신청 완료 메시지를 확인하세요. 폼은 실제 전송하지 않습니다.

신청 완료!
