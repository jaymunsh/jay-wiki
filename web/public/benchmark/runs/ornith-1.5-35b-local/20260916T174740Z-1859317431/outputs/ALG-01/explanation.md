# ALG-01 설명: 겹치지 않는 작업의 최대 가치

## 알고리즘

Weighted Interval Scheduling(가중 구간 스케줄링) DP입니다.

1. 모든 작업을 `end` 오름차순(동률이면 `start` 오름차순)으로 정렬합니다. 입력 배열은
   `slice()`로 복사한 뒤 정렬해 원본을 변경하지 않습니다.
2. 정렬된 끝 시각 배열 `ends`를 만듭니다.
3. `dp[i]` = 정렬된 앞선 `i`개 작업을 고려했을 때 선택할 수 있는 작업 가치 합의 최댓값으로
   정의합니다. `dp[0] = 0`이고目标是 `dp[n]`입니다.
4. `i`번째 작업(정렬된 배열의 `i-1`번 인덱스)을 처리할 때:
   - `latestCompatible(ends, start, i-1)`으로 **이진 탐색**해 `end <= start`인 가장 늦은
     작업의 인덱스를 찾습니다. 이 작업까지 고려했을 때의 최대값은 `dp[인덱스+1]`입니다.
   - 포함 선택: `value + (호환 작업이 있으면 그 dp 값, 없으면 0)`
   - 미선택 선택: `dp[i-1]`
   - `dp[i] = Math.max(포함, 미선택)`

`start` 이하로 끝나는 가장 늦은 작업을 이진 탐색으로 찾는 것이 핵심입니다. 이로 인해
각 작업을 상수 시간에 السابق 최적값과 결합할 수 있습니다.

## 맞는 이유

정렬된 순서에서는 항상 `end`가 증가하므로, 현재 작업과 겹치지 않는 이전 작업들 중 끝이
가장 늦은 것만 찾으면 됩니다(그것이 최대 가치를 남기 때문이다). `latestCompatible`는
`end <= start`를 만족하는 가장 큰 인덱스를 찾으니, 그 작업의 끝은 현재 작업의 시작보다
이전 또는 같아 겹치지 않습니다(반열린 구간 `[start, end)`이 끝과 시작이 같으면 허용).

DP 전이는 "현재 작업을 포함한다/않한다"의 두 선택으로 최적 부분 구조를 만족합니다.
미선택 시 `dp[i-1]`이 이전까지의 최댓값을 이미 담고 있으므로 모든 부분 집합을 커버합니다.

## 시간·공간 복잡도

- 시간: 정렬 `O(n log n)` + 각 작업당 이진 탐색 `O(log n)` × `n` = 총 `O(n log n)`.
- 공간: 정렬 복사 `O(n)`, `ends` `O(n)`, `dp` `O(n)` = `O(n)`.

입력 배열은 `slice()`로만 복사하므로 원본은 변경되지 않습니다.

## 직접 확인한 경계 사례

- 빈 입력 `[]` → `0`.
- 인접 작업 `[0,5,3],[5,10,4]` → 끝과 시작이 같아 함께 선택, `7`.
- 동일 구간 중복 `[2,4,7],[2,4,9]` → 겹치므로 최대 `9`.
- `[6,8,14],[7,12,6],[11,13,5]` → `[6,8,14]`와 `[11,13,5]`는 `11>=8`으로 호환, 합 `19`
  ( `[7,12,6]`은 `[6,8,14]`와 `7<8`로 겹침).
- 극한 값 `[0,1_000_000_000,1_000_000_000]` → `1_000_000_000`, 합도 JS 안전 정수 범위 내.
- 200,000 작업 대규모 입력도 40ms 이내 처리(테스트 실행 결과 참조).
