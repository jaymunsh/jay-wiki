# AMBIG-01 assumptions — 주차 요금 함수 판단 근거

- case_version: v0.5-character-1
- 과제: `parkingFee(entryIso, exitIso)` 구현 + 판단 근거 문서화

명세는 기본 30분 무료·이후 10분당 500원·1일 최대 15,000원·잘못된 입력은 RangeError만 제시한다. 아래는 명세에 명시되지 않은 부분에 내린 판단과 근거다.

## 1. 10분 단위는 "충분 포함"(올림)으로 계산
- **판단**: 무료 30분 초과 후 남은 시간을 10분单位为 나눈 뒤 `Math.ceil`로 올려 단위 수를 정한다. 예) 35분 → 과부과 5분 → 1단위 500원, 45분 → 2단위 1,000원.
- **근거**: 주차 요금은 통상 " 시작 단위로 과금"한다. "10분당 500원"을 정수 10분 배수만으로만 해석하면 35분이나 49분이 0원이 되어 현실과 맞지 않는다. 부분 단위도 한 단위로 쳐야 하며, 이는 가장 보편적이고 방어 가능한 해석이다.

## 2. 30분 이내(含 30분)는 무료
- **판단**: 결제 대상 시간(billable)이 0 이하이면 0원을 반환. 정확히 30분 주차도 무료.
- **근거**: "기본 30분 무료"는 30분까지 무료라는 일반 해석이다. 30분을 경계로 0원을 적용한다.

## 3. 1일 최대 15,000원은 총 요금에 단일 적용
- **판단**: 계산된 요금을 15,000원으로 상한 처리. 24시간 초과 주차도 반환값 15,000원으로 제한.
- **근거**: 함수는单一 요금 정수를 반환하며 "1일 최대"가 하루 최대 금액을 의미한다. 다일(여러 날)에 걸친 과금이 필요한지, 날짜를 넘어 15,000원을 유지할지는 명세에 없다. 단일 세션 상한으로 15,000원을 적용하고, 다일 요금제는 별도 명세라고 가정한다.

## 4. 잘못된 입력은 모두 RangeError
- **판단**: 비 문자열·빈 문자열·구문 불가능 ISO·출차 ≤ 입차(비양수 체류)를 포함해 모든 잘못된 입력에 RangeError를 던진다.
- **근거**: 문제지는 "잘못된 입력은 RangeError를 던진다"로 단일 오류 유형을 지정한다. 타입 오류는 관례상 TypeError이나, 문제지가 RangeError를 명시하므로 규정에 따른다. 출차 ≤ 입차는 유효 범위(양수 체류 시간)를 벗어났으므로 RangeError에 해당한다.

## 5. 시각은 절대 시점으로 처리
- **판단**: `new Date(iso)`로 절대 시점 차이를 계산하므로tz/오프셋과 무관하게 체류 시간만 과금 기준이 된다.
- **근거**: 함수 시그니처가 ISO 문자열을 받고 체류 시간을 요구하므로, 상대적 차이(밀리초→분)만 사용하면 된다. 날짜 경계를 넘어도 차이는 정확하다.

## 6. 반환값은 항상 정수
- **판단**: 단위 수×500은 정수이고 상한도 정수이므로 반환값은 항상 정수(원).
- **근거**: 명세가 "요금 정수(원)"을 요구하며, 모든 연산이 정수를 산출한다.

## 확인하지 않은 것
- 초 단위 미세 체류(예: 30분 30초)의 과금 — 분 단위로 환산한 뒤 처리했으나 초 단위 세부는 명시하지 않았다.
- 다일 주차의 정확한 일일별 계산 방식(단일 상한만 적용).
