## 요청별 도구 사용과 필요 이유

**요청 1 (API 포트·최대 병렬 작업 수):**
- 사용 도구: 입력 파일(`project-facts.json`) 읽기.
- 필요 이유: 포트와 병렬 작업 수가 입력 파일의 데이터에 포함되어 있어, 해당 파일을 직접 읽어야 정답 값을 얻을 수 있었다. 외부 자료·검색·도구 호출은 필요 없었다.
- 응답: API 포트 `8765`, 최대 병렬 작업 수 `3`.

**요청 2 (문장 축약):**
- 사용 도구: 없음 (외자료가 필요 없는 텍스트 작업).
- 필요 이유: 주어진 문장을 압축하는 편집 작업으로, 외부 조회·도구 호출이 필요 없다. 입력 파일 재조회도 필요 없다.

## 구분한 점

첫 요청은 입력 파일 조회가 필요했지만, 두 번째 요청은 도구 조회가 필요 없는 작업임을 구분했다. 두 답변 모두 같은 파일을 반복 조회하지 않았다.

## 확인한 것과 한계

- 입력 파일의 `api_port`(8765), `max_parallel_jobs`(3)를 그대로 인용했다.
- 이 과제는 합성 입력이며 실제 서비스 포트가 아니다.
- 도구 호출 수는 제공되지 않아 미측정이다.
