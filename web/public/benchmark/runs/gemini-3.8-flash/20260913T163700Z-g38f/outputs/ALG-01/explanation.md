# ALG-01: 겹치지 않는 작업의 최대 가치 합 (설명 문서)

## 1. 알고리즘 설계
본 문제는 가중치 기반 구간 스케줄링(Weighted Interval Scheduling) 문제로, **정렬(Sorting) + 동적 계획법(Dynamic Programming) + 이진 탐색(Binary Search)**을 결합하여 해결한다.

1. **입력 검증 및 복사**:
   - 입력 배열의 불변성을 유지하기 위해 원본 `jobs`를 복사한 새 배열을 생성한다.
   - 동시에 모든 원소의 길이(3개), 유한 정수 여부, `0 <= start < end <= 1,000,000,000`, `0 <= value <= 1,000,000,000` 범위를 엄격히 검증하여 위반 시 `RangeError`를 던진다.
2. **종료 시각 기준 정렬**:
   - 복사된 작업들을 종료 시각 `end` 오름차순으로 정렬한다.
3. **DP 점화식 및 이진 탐색**:
   - `dp[i]`를 "1번째부터 `i`번째 작업까지 고려했을 때 겹치지 않게 선택할 수 있는 최대 가치 합"으로 정의한다 (`dp[0] = 0`).
   - `i`번째 작업 `[s, e, v]`에 대해 두 가지 선택지를 비교한다:
     - 작업을 선택하지 않는 경우: `dp[i - 1]`
     - 작업을 선택하는 경우: 현재 가치 `v` + `end <= s`를 만족하는 가장 늦은 이전 작업 `j`의 최적해 `dp[j]`
   - 정렬된 종료 시각 배열에서 `end <= s`인 최우측 작업 `j`를 이진 탐색(`O(log n)`)으로 빠르게 찾는다.
   - `dp[i] = Math.max(dp[i - 1], dp[j] + v)`

## 2. 정당성 (Correctness)
종료 시각 기준으로 작업을 정렬하면, `i`번째 작업과 겹치지 않는 이전 작업들은 모두 `i`번째 작업보다 앞선 인덱스에 존재하며, 그중 `end <= s`인 범위에 속한 작업들 중 최적해는 이미 부분 문제의 최적 부분 구조(Optimal Substructure)에 의해 `dp[j]`에 기록되어 있다. 따라서 모든 가능한 선택지(포함/비포함)를 빠짐없이 탐색하되 중복 계산을 배제하여 최적의 해를 보장한다.

## 3. 복잡도 분석
- **시간 복잡도**: `O(n log n)`
  - 정렬에 `O(n log n)`, `n`개 작업 각각에 대해 이진 탐색 `O(log n)`을 수행하므로 전체 `O(n log n)`이다.
  - 최대 입력 `n = 200,000`에서 약 73ms 만에 실행 완료됨을 실측 검증하였다.
- **공간 복잡도**: `O(n)`
  - 입력 불변성을 위한 복사 배열 `O(n)`과 DP 배열 `O(n)`만을 사용하여 메모리를 안전하게 관리한다.

## 4. 직접 확인한 경계 사례
- **빈 배열 (`[]`)**: 즉시 `0` 반환 확인.
- **경계 접촉 (`[0, 10, 5], [10, 20, 5]`)**: 반열린 구간 `[start, end)` 규칙에 따라 접촉 시 겹치지 않으므로 합 `10` 반환 확인.
- **동일 구간 다중 작업 (`[0, 5, 3], [0, 5, 10], [0, 5, 2]`)**: 가치 최댓값 `10` 정상 선택 확인.
- **가치 0 작업**: 유효 입력으로 정상 수용 확인.
- **최대 좌표 (`1,000,000,000`)**: 오버플로 없이 JavaScript 안전 정수 범위 내 연산 확인.
- **입력 불변성**: `Object.freeze`된 입력 배열에 대해 원본 변형 없이 정상 동작 확인.
- **오류 입력 (음수, `start >= end`, 실수, 비정수, 잘못된 길이 등)**: 정확히 `RangeError` 발생 확인.
