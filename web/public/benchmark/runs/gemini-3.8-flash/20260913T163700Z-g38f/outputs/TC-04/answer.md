# TC-04 상품 정보 조회 결과

모의 서비스(`catalog.quote`)를 통해 조회한 상품 정보는 다음과 같습니다.

## 1. 상품 코드: LNU-USB
- 첫 번째 조회 시도에서 `TEMP_UNAVAILABLE` (일시적 서비스 오류, 재시도 가능) 응답을 수신하여 즉시 1회 재시도(retry)를 수행하였습니다.
- 재시도 결과 성공적으로 상품 정보를 수신하였습니다:
  - **상품명 (name)**: Leneu USB Hub
  - **단가 (unit_price_won)**: 32,000원
  - **재고 (stock)**: 7개

---

## 2. 상품 코드: NO-SUCH-ITEM
- 조회 결과, 상품을 찾을 수 없다는 오류 응답을 확인하였습니다:
  - **결과**: `NOT_FOUND` (오류 코드)
  - **오류 메시지**: `unknown sku`
  - **재시도 가능 여부**: `false` (재시도 불가 오류)
- 해당 상품은 카탈로그에 존재하지 않는 미등록 상품입니다.
