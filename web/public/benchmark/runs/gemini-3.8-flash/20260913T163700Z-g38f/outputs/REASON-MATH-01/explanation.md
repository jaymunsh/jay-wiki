# REASON-MATH-01 계산식 및 경계 분석

## 1. 문항별 상세 계산식

### M1: 250장 주문 시 할인 전 종이 요금
- 첫 100장: $100 \text{장} \times 120\text{원} = 12,000\text{원}$
- 초과 150장 (101~250번째): $150 \text{장} \times 90\text{원} = 13,500\text{원}$
- 할인 전 종이 요금: $12,000\text{원} + 13,500\text{원} = \mathbf{25,500\text{원}}$

### M2: 같은 주문의 할인 뒤 종이 요금
- 주문 장수 250장은 200장 이상이므로 10% 전체 할인 적용.
- 할인 금액: $25,500\text{원} \times 0.10 = 2,550\text{원}$
- 할인 뒤 종이 요금: $25,500\text{원} \times (1 - 0.10) = \mathbf{22,950\text{원}}$

### M3: 같은 주문의 배송비 포함 최종 금액
- 배송비 기준: 할인 뒤 종이 요금이 20,000원 이상이면 무료(0원).
- $22,950\text{원} \ge 20,000\text{원}$이므로 배송비는 0원.
- 최종 금액: $22,950\text{원} + 0\text{원} = \mathbf{22,950\text{원}}$

### M4: 125장씩 두 주문으로 분할 주문 시 총액
- 125장은 200장 미만이므로 10% 할인 미적용.
- 한 주문(125장)의 종이 요금:
  - 첫 100장: $100 \times 120 = 12,000\text{원}$
  - 초과 25장: $25 \times 90 = 2,250\text{원}$
  - 종이 요금 합계: $12,000 + 2,250 = 14,250\text{원}$
- 14,250원은 20,000원 미만이므로 배송비 2,500원 부과.
- 한 주문당 최종 금액: $14,250\text{원} + 2,500\text{원} = 16,750\text{원}$
- 두 주문의 총액: $16,750\text{원} \times 2 = \mathbf{33,500\text{원}}$

## 2. M5: 무료 배송이 적용되는 최소 정수 장수 분석 및 경계 비교

주문 장수를 $x$라 할 때, 할인 뒤 종이 요금이 20,000원 이상이 되는 최소 정수 $x$를 구한다.

### 구간 1: $101 \le x < 200$ (10% 할인 미적용 구간)
- 종이 요금 정가: $100 \times 120 + (x - 100) \times 90 = 90x + 3,000$ (원)
- 무료 배송 조건: $90x + 3,000 \ge 20,000 \iff 90x \ge 17,000 \iff x \ge \frac{1,700}{9} \approx 188.89$
- 정수 $x$의 최솟값은 **189장**.
- **경계값 비교**:
  - $x = 188$장: 요금 $90 \times 188 + 3,000 = 16,920 + 3,000 = 19,920$원 (< 20,000원 $\rightarrow$ 배송비 2,500원 부과)
  - $x = 189$장: 요금 $90 \times 189 + 3,000 = 17,010 + 3,000 = 20,010$원 ($\ge 20,000$원 $\rightarrow$ **무료 배송 적용**)
  - $x = 199$장: 요금 $90 \times 199 + 3,000 = 17,910 + 3,000 = 20,910$원 ($\ge 20,000$원 $\rightarrow$ 무료 배송 적용)

### 구간 2: $x \ge 200$ (10% 할인 적용 구간)
- 200장 이상 주문 시 10% 할인이 적용되므로, 할인 뒤 종이 요금은:
  $(90x + 3,000) \times 0.9 = 81x + 2,700$ (원)
- $x = 200$장의 경우:
  - 정가: $90 \times 200 + 3,000 = 21,000$원
  - 할인 후: $21,000 \times 0.9 = 18,900$원 (< 20,000원 $\rightarrow$ **할인으로 인해 배송비 2,500원 다시 발생**)
- $x \ge 200$ 구간에서 무료 배송이 되려면:
  $81x + 2,700 \ge 20,000 \iff 81x \ge 17,300 \iff x \ge \frac{17,300}{81} \approx 213.58$
  즉, $x \ge 214$장이어야 함.
  - $x = 213$장: $(90 \times 213 + 3,000) \times 0.9 = 22,170 \times 0.9 = 19,953$원 (< 20,000원 $\rightarrow$ 유료 배송)
  - $x = 214$장: $(90 \times 214 + 3,000) \times 0.9 = 22,260 \times 0.9 = 20,034$원 ($\ge 20,000$원 $\rightarrow$ 무료 배송)

### 결론
189장~199장 구간에서는 할인이 적용되지 않아 요금이 20,000원을 넘어 무료 배송이 적용되고, 200장~213장 구간에서는 10% 할인으로 20,000원 미만으로 떨어져 배송비가 발생하며, 214장부터 다시 무료 배송이 된다.
따라서 무료 배송이 적용되는 가장 작은 정수 장수는 **189장**이다.
