# REASON-MATH-01 결과 보고서

- 과제 ID: REASON-MATH-01
- 문제 버전: 1
- 상태: submitted
- 타이밍 출처: agent-observed (benchmark.py harness)
- 토큰/비용/속도: 미측정 (not_exposed)

## 수행 내용
1. 문제에 제시된 구간별 단가(100장 이하 120원, 101장 이상 90원), 200장 이상 10% 할인, 배송비 조건(할인 뒤 20,000원 이상 무료)을 순수 모델 내부 연산으로 풀이.
2. 외부 검색, 계산기 프로그램, 코드 실행을 통한 자동 계산 없이 순수 수리 추론으로 5개 항목 산출:
   - M1: 25500 (250장 할인 전 종이 요금)
   - M2: 22950 (250장 10% 할인 뒤 종이 요금)
   - M3: 22950 (무료 배송 적용 최종 금액)
   - M4: 33500 (125장 2회 분할 주문 시 총액)
   - M5: 189 (무료 배송 최소 정수 장수; 200장 경계 역전 현상 분석 포함)
3. 정수 JSON(`answers.json`) 및 수식/경계 비교 문서(`explanation.md`) 작성 완료.

## 도구 사용 및 한계
- 사용한 도구: 산출물 파일 저장을 위한 파일 쓰기 명령만 수행 (코드 기반 계산 금지 규칙 준수).
- 독립 채점: 자체 점수는 매기지 않으며, 평가자의 채점을 위해 미채점으로 보존함.
