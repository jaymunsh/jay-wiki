# AMBIG-01 판단 근거 문서 (assumptions.md)

본 문서는 `solution.mjs` 구현 과정에서 명세에 명시되지 않은 모호성 및 누락 사항을 식별하고, 이에 대해 내린 기술적 의사결정과 판단 근거를 기술한다.

---

## 1. 10분 단위 절상(Ceiling) 처리 방식

- **모호점**: "이후 10분당 500원" 규칙에서 10분 미만의 자투리 시간(예: 31분 주차 시 무료 30분을 초과한 1분)에 대한 처리 기준(올림, 버림, 반올림)이 명시되지 않음.
- **판단**: **10분 단위 올림(`Math.ceil`)** 적용.
- **근거**: 일반적인 상업용 주차 시스템 및 표준 요금 부과 정책상, 과금 단위 시간에 1초라도 진입하면 해당 단위 전체 요금을 부과하는 것이 보편적 관례임. 따라서 31분 주차 시 초과 1분에 대해 500원이 부과됨(31~40분: 500원, 41~50분: 1,000원).

---

## 2. 기본 30분 무료의 소급 적용 여부

- **모호점**: 30분 초과 시 첫 30분을 공제(무료 인정)하는지, 아니면 30분을 초과하는 순간 첫 30분까지 소급하여 40분 요금(2,000원)을 부과하는지 명시되지 않음.
- **판단**: **기본 30분 공제 유지**.
- **근거**: "기본 30분 무료, 이후 10분당 500원"이라는 문구는 30분까지는 요금이 발생하지 않으며 과금 대상 시간은 `총 주차 시간 - 30분`으로 산정됨을 의미함. 31분 이용자에게 소급하여 2,000원을 부과하는 것은 '무료'의 통상적 계약 의미에 부합하지 않음.

---

## 3. 1일(24시간) 주기의 정의 및 다일 주차 상한

- **모호점**: "1일 최대 15,000원"에서 1일의 기준이 '자정(00:00) 기준 달력일'인지 '입차 시각 기준 24시간 연속 주기'인지 명시되지 않음.
- **판단**: **입차 시각 기준 연속 24시간 블록(Rolling 24-hour cycle)** 적용.
- **근거**:
  1. 달력 자정 리셋 방식을 취할 경우, 23시 50분에 입차하여 00시 10분에 출차(총 20분 주차)한 이용자가 자정을 넘겼다는 이유로 일자가 분할되어 무료 혜택이나 상한 계산에서 불이익을 받을 수 있음.
  2. 24시간을 초과하는 장기 주차의 경우, 각 완전한 24시간마다 15,000원의 상한이 누적되며, 마지막 잔여 시간에 대해서는 시간 비례 요금(15,000원 상한)이 추가 합산됨.
  3. 최초 30분 무료 혜택은 입차 시 1회 제공되는 성격으로 보아, 2일차 이후 잔여 시간에 대해서는 30분 무료를 재적용하지 않고 10분당 500원을 즉시 부과(일일 최대 15,000원 한도 내)함.

---

## 4. 잘못된 입력의 예외 처리 범위

- **모호점**: "잘못된 입력은 RangeError를 던진다"의 구체적 범위.
- **판단**:
  1. 문자열 타입이 아닌 입력(`null`, `undefined`, `number` 등) -> `RangeError`
  2. ISO 8601 포맷으로 파싱 불가능한 문자열(`Date.parse(s)` 결과가 `NaN`) -> `RangeError`
  3. 출차 시각이 입차 시각보다 이른 시간 역전(`exitIso < entryIso`) -> `RangeError`
- **근거**: JavaScript 표준에서 유효 범위를 벗어난 인자나 시간 역전에 대해 `RangeError`를 명시적으로 요구했으므로, 잘못된 포맷 및 논리적 모순값을 모두 `RangeError`로 통일 처리함.
