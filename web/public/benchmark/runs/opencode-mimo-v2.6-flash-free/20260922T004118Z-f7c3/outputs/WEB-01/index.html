기능

작업 기록

모델별 프롬프트, 산출물, 소요 시간, 메모를 하나의 기록으로 남깁니다. 같은 작업이라도 모델과 시도별로 구분해 쌓입니다.

결과 비교

같은 작업의 여러 결과를 나란히 놓고 채택·보완 여부를 표시합니다. 어느 모델이 어떤 조건을 놓쳤는지 한눈에 정리됩니다.

Markdown 내보내기

정리한 기록을 그대로 Markdown 문서로 내보냅니다. 블로그 초안, 팀 공유 메모, 개인 아카이브에 그대로 붙여 넣을 수 있습니다.

사용 흐름

기록에서 비교, 내보내기까지 네 단계입니다.

작업 등록

할 작업과 조건을 등록합니다. 모델 이름과 시도 회차를 함께 적습니다.

결과 기록

각 모델의 응답과 산출물, 관측한 시간을 기록합니다.

비교·채택

결과를 나란히 두고 채택안과 보완점을 표시합니다.

내보내기

정리된 비교표를 Markdown으로 내보내 공유합니다.
