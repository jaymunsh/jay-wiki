# 결제 승인 지연 관련 사과 안내

고객님께 안내드립니다.

9월 14일 14시 02분부터 15시 47분(KST)까지 약 105분 동안 결제 승인 요청이 지연 처리되었습니다. 결제가 거절된 것은 아니며, 해당 시간대에 결제를 시도하신 고객님의 승인 처리가 평소보다 늦게 완료된 것입니다.

확인 결과, 원인은 당일 배포 시 데이터베이스 커넥션 풀 크기 설정이 누락되어 풀이 고갈된 것이었습니다. 해당 설정을 복구하였고, 지연된 승인 312건은 전부 정상 처리 완료되었습니다. 중복 결제와 오청구는 발생하지 않았습니다.

재발 방지를 위해 풀 크기 항목을 배포 체크리스트에 추가하여 이후 배포 단계에서 누락을 방지하겠습니다. 이용에 불편을 끼쳐 죄송합니다. 추가 문의가 있으시면 고객센터로 연락 주시면 신속히 안내해 드리겠습니다.
