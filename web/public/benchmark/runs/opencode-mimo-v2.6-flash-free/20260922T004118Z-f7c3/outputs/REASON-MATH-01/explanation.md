# REASON-MATH-01 설명 (외부 계산기·코드 없이 수기 계산)

규칙 요약: 첫 100장 장당 120원, 101장부터 장당 90원. 200장 이상 주문이면 종이 요금 전체 10% 할인. 배송비는 **할인 뒤** 종이 요금이 20,000원 이상이면 0원, 미만이면 2,500원. 반올림 없음.

- **M1 (250장 할인 전):** 100 × 120 + 150 × 90 = 12,000 + 13,500 = **25,500원**
- **M2 (할인 뒤):** 250 ≥ 200이므로 25,500 × 0.9 = **22,950원**
- **M3 (배송비 포함):** 22,950 ≥ 20,000 → 배송비 0원 → **22,950원**
- **M4 (125장 × 2주문):** 한 주문당 (할인 전) 100 × 120 + 25 × 90 = 12,000 + 2,250 = 14,250원. 125 < 200이므로 할인 없음. 14,250 < 20,000 → 배송비 2,500원 → 주문당 16,750원. 두 주문 합 = 16,750 × 2 = **33,500원**. (서로 다른 주문은 각각 계산하므로 나누는 것이 불리함을 확인할 수 있다: 250장 한 주문은 22,950원이었다.)
- **M5 (무료 배송 최소 정수 장수):** n ≥ 100일 때 할인 전 종이 요금 = 12,000 + 90(n − 100).

  1. **n < 200 (할인 전):** 12,000 + 90(n − 100) ≥ 20,000 ⇔ 90(n − 100) ≥ 8,000 ⇔ n − 100 ≥ 88.88… ⇔ n ≥ 189.
     - 경계: n = 188 → 12,000 + 7,920 = 19,920 < 20,000 (배송비 2,500). n = 189 → 12,000 + 8,010 = **20,010 ≥ 20,000 (무료)**.
  2. **n ≥ 200 (할인 적용):** 종이 요금 = (3,000 + 90n) × 0.9 ≥ 20,000 ⇔ 3,000 + 90n ≥ 22,222.2… ⇔ 90n ≥ 19,222.2… ⇔ n ≥ 213.58… ⇔ **n ≥ 214**.
     - 경계: n = 200 → (3,000 + 18,000) × 0.9 = 18,900 < 20,000 (할인 때문에 오히려 배송비 발생). n = 213 → (3,000 + 19,170) × 0.9 = 19,953 < 20,000. n = 214 → (3,000 + 19,260) × 0.9 = 20,034 ≥ 20,000 (무료).
  3. n < 100이면 최대 99 × 120 = 11,880 < 20,000이라 불가능.

  189(할인 구간 이전)과 214(할인 구간) 중 최솟값은 **189**. 무료 배송 가능 여부는 n = 200에서 할인 때문에 다시 끊어지는 비단조 경계임을 1·2의 경계 비교에서 확인했다. 따라서 **M5 = 189장**.
