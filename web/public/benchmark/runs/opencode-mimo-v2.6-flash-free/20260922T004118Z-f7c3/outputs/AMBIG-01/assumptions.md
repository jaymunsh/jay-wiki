# AMBIG-01 — 구현 판단 문서화

명세: 기본 30분 무료 / 이후 10분당 500원 / 1일 최대 15,000원 / 잘못된 입력은 RangeError. 명세에 없어 내가 결정한 사항:

1. **단위 올림 규칙**: "10분당 500원"이 구간 단위(0분 초과~10분=1단계)인지 명시가 없다. 주차 과금 관례에 따라 **창끝 올림**(`ceil`)을 채택 — 31분 초과분 1분도 500원 추가. 대안(내림)이면 30분+1분이 공짜가 되어 과거 시스템 오남용 소지가 크다.
2. **무료 시간 적용 위치**: 주차 총시간에서 30분을 먼저 뺀 뒤 과금. (a) 총시간 기준과 (b) 유료분만 쪼개는 방식은 10분 경계에서 동일해지도록 설계했고, 총시간 기준을 채택했다.
3. **일 최대 한도**: 누적 주차가 24시간을 넘는 경우는 명세가 "1일 최대"만 규정. 구간 합계가 15,000원을 넘으면 **해당 호출 결과를 15,000으로 캡**(한 번의 입출차 시각 차이로 계산). 24시간 초과 주차를 일 단위로 쪼개 청구하는 정책은 명세에 없어 구현하지 않음(과제는 `entryIso, exitIso` 두 점만 주어짐).
4. **경계 포함**: 무료 30분 정확히 → 0원. 30분 1초 → 500원(1단계).
5. **과거/미래 시각**: 시각 자체가 과거여도 `entry <= exit`이면 계산(검증만 수행). "과거 시각 거부"는 명세에 없음.
6. **RangeError 판정 범위**: (a) ISO 문자열이 아닌 타입, (b) `Date.parse` 실패, (c) `exit < entry` — 셋 다 RangeError.
7. **타임존**: `Date.parse`가 해석하는 오프셋을 그대로 쓰고, 없는 오프셋 입력은 로컬 타임존으로 해석되는 JS 표준 동작을 따름(명세가 오프셋 요구를 안 함).
8. **소수 초 보정**: 밀리초 단위 차이도 그대로 반영(초 단위 반올림 없음 — "반올림" 언급이 명세에 없음).
9. **캐시/할인/월 단위 한도**: 언급 없어 미적용.
