# Apple Silicon Mac(통합 메모리 64GB) 로컬 LLM 비교: Ollama, llama.cpp, LM Studio

조사 기준일: 2026-09-13. 용도는 한국어 글쓰기와 코딩 도구 연동이다. 직접 설치·측정하지 않았으며 속도·메모리·비용 수치는 싣지 않는다.

## 비교표

| 기준 | Ollama | llama.cpp | LM Studio |
|---|---|---|---|
| 설치·운영 방식 | 앱·CLI 설치 후 `ollama pull/run/serve`로 모델 관리·실행(공식 저장소 README). 데스크톱 없이 `ollama serve`로 기동한다 | 설치 경로가 여러 개이다. llama.app 안내, Docker, 릴리스 바이너리, 소스 빌드 중 선택한다(공식 저장소 README). 실행은 `llama cli/serve`이다 | 데스크톱 앱을 내려받아 모델 검색·다운로드·채팅·서빙을 GUI로 한다(공식 문서). `lms server start`로 로컬 서버를 켠다 |
| 지원 모델 형식 | 모델 라이브러리에서 내려받거나 GGUF를 Modelfile `FROM`으로 가져온다(공식 문서 Import). GGUF 양자화(q4_K_M 등)를 그대로 쓴다 | GGUF 형식이 필수이며, 다른 형식은 저장소의 변환 스크립트로 GGUF로 바꾼다(공식 저장소 models 문서) | llama.cpp(GGUF) 또는 MLX 모델을 실행한다. Apple Silicon Mac에서는 MLX도 지원한다(공식 문서) |
| 로컬 API | 기본 `http://localhost:11434/api`, OpenAI 호환 `http://localhost:11434/v1/`를 제공한다(공식 문서 API 소개·OpenAI 호환). API 키는 요구되나 무시된다 | OpenAI 호환 API 서버를 제공한다(공식 저장소 README). 기본 포트는 8080이다(서드파티 허브 문서, 공식 문서 미열람) | Developer 탭·`lms`로 서버를 켜고 localhost 또는 네트워크에 서빙한다(공식 문서). OpenAI 호환·Anthropic 호환·REST·SDK를 제공한다. 기본 포트는 1234이다(서드파티 문서, 공식 문서 미열람) |
| 툴 호출 조건 | 단일·병렬·다회전 호출을 API로 지원한다(공식 문서 Tool calling 원문 열람). OpenAI 호환 `/v1/chat/completions`에서도 Tools를 지원하나 `tool_choice`는 미지원이다(공식 문서 OpenAI 호환). API 지원과 별개로 모델별 능력은 다르다는 점에 유의한다 | 웹에서 툴 호출 조건을 확인하지 못해 미확인으로 둔다 | 모든 모델이 최소 수준의 도구 사용은 되나 품질에 따라 네이티브와 기본 두 단계로 나뉜다(공식 문서 Tool Use). 네이티브는 도구 학습된 템플릿+형식 지원이 갖춰진 경우이며, 나머지는 기본 지원이다. 작은 모델·미학습 모델은 형식이 깨질 수 있다 |
| 오프라인 조건 | 모델을 받아 둔 뒤 로컬 실행한다. 클라우드 모델은 네트워크가 필요하다(공식 문서). 완전 오프라인 보장은 별도로 확인하지 못해 미확인으로 둔다 | 로컬 추론용이며 모델 파일이 있으면 로컬에서 돈다. 설치 시 다운로드가 필요하고, 완전 오프라인 동작 문구는 웹에서 확인하지 못해 미확인으로 둔다 | 모델 파일을 먼저 받아 두면 완전 오프라인 동작이 가능하다(공식 문서). 단 이 문구만 확인했고 실제 차단 환경에서 시험하지 않았다 |

## 조건별 추천

- 손쉬운 CLI·코딩 도구 연동이 우선이면 Ollama를 먼저 둔다. OpenAI 호환 경로와 도구 호출 문서가 갖춰져 있고, llama.cpp 기반 GGUF 자산을 Modelfile로 가져올 수 있다(공식 문서).
- 빌드·백엔드·서버 옵션을 직접 통제하고 싶으면 llama.cpp를 둔다. Apple Silicon이 최적화 대상에 포함되고 양자화 선택지가 넓다(공식 저장소 README). 다만 툴 호출 조건은 웹에서 추가로 확인할 일이다.
- GUI에서 모델을 고르고 서버·MCP까지 한 화면에서 다루려면 LM Studio를 둔다. MLX 실행과 오프라인 문구가 공식 문서에 있다. 모델별 도구 사용 단계(네이티브·기본)를 확인하고 고른다.

## 미확인 사항

- 세 도구 모두 64GB Mac에서의 실측 속도·메모리 사용·비용을 재지 않았다.
- llama.cpp의 웹 기준 툴 호출 조건, Ollama·llama.cpp의 완전 오프라인 보장 문구는 이번 조사에서 확인하지 못했다.
- 기본 포트(11434·1234·8080)는 문서 기준이며 버전·설정에 따라 달라질 수 있다.
- 한국어 글쓰기 품질은 모델별 문제이므로 도구 비교만으로 정하지 못한다.
