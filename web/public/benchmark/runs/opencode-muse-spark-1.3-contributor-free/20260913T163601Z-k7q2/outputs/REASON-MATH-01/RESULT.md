| 문항 | 값 | 단위 | 계산식 |

| M1 | 25500 | 원 | `100×120 + 150×90 = 12,000 + 13,500` |

## 경계 검증 요약

- **M5 경계**: 189장 → 20,010원(무료), 188장 → 19,920원(배송비). 200장 이상 구간은 214장 → 20,034원(무료), 213장 → 19,953원(배송비). 최솟값은 189장.
- **200장 할인 경계 함정**: 200장은 할인 뒤 18,900원으로 오히려 무료 배송 조건에 미달한다.

- **사용한 도구**: 없음. 요금 규칙을 손으로 계산했다(외부 검색·계산기·코드 실행 미사용).
- **한계**:
  - 모든 값은 출제자가 만든 **가상 요금 규칙**에 근거한다.
  - 계산 중 반올림이 없다는 조건에 따라 모든 값이 정수로 떨어졌다.
  - 자기 점수와 합격 판정은 만들지 않았다. 정답 점수와 근거 점수는 별도 평가가 필요하다.
