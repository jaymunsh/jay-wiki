# REASON-MATH-01 해설

지문의 요금 규칙만 사용해 손으로 계산했다. 외부 검색·계산기·코드 실행을 사용하지 않았다.

## 요금 규칙 정리

- 첫 100장까지 장당 120원, 101번째 장부터 장당 90원.
- 200장 이상 주문 시 **종이 요금 전체**에서 10% 할인.
- 배송비: **할인 뒤** 종이 요금이 20,000원 이상이면 무료, 미만이면 2,500원.
- 부가세 없음, 계산 중 반올림 없음. 서로 다른 주문은 장수·배송비를 각각 계산.

n장 주문의 할인 전 종이 요금을 `f(n)`이라 하면:

- `f(n) = 120n` (n ≤ 100)
- `f(n) = 12,000 + 90(n − 100) = 3,000 + 90n` (n > 100)

## M1 — 250장 한 번에 주문, 할인 전 종이 요금 = 25,500원

- 첫 100장: `100 × 120 = 12,000`
- 나머지 150장: `150 × 90 = 13,500`
- 합계: `12,000 + 13,500 = 25,500`

## M2 — 같은 주문의 할인 뒤 종이 요금 = 22,950원

- 250 ≥ 200이므로 10% 할인 적용: `25,500 × 0.9 = 22,950`
- 반올림 없음(22,950은 정수).

## M3 — 배송비 포함 최종 금액 = 22,950원

- 할인 뒤 종이 요금 22,950 ≥ 20,000 → **배송비 무료**.
- 최종 금액: `22,950 + 0 = 22,950`

## M4 — 125장씩 두 주문의 배송비 포함 총액 = 33,500원

주문 1건(125장) 기준:

- 할인 전: 첫 100장 `100 × 120 = 12,000`, 나머지 25장 `25 × 90 = 2,250` → `14,250`
- 125 < 200이므로 **할인 없음** → 할인 뒤 종이 요금 `14,250`
- 14,250 < 20,000 → 배송비 `2,500`
- 주문 1건 합계: `14,250 + 2,500 = 16,750`

두 주문 합계: `16,750 × 2 = 33,500`

(참고: 한 주문 250장은 22,950원인데 125장씩 나누면 33,500원이 되어, 분할이 더 비싸다.)

## M5 — 무료 배송 최소 정수 장수 = 189장

무료 배송 조건은 **할인 뒤** 종이 요금 ≥ 20,000원이다. 할인 적용 여부에 따라 두 구간으로 나눠 본다.

**구간 A — 할인 미적용 (n < 200)**

- n ≤ 100: `f(n) = 120n ≤ 12,000 < 20,000` → 불가.
- 100 < n < 200: `f(n) = 3,000 + 90n ≥ 20,000` → `90n ≥ 17,000` → `n ≥ 188.88…` → `n ≥ 189`.
  - 경계 확인: `f(189) = 3,000 + 17,010 = 20,010 ≥ 20,000` (무료)
  - 직전값: `f(188) = 3,000 + 16,920 = 19,920 < 20,000` (배송비 발생)
- 구간 A의 최솟값: **189장**

**구간 B — 할인 적용 (n ≥ 200)**

- `0.9 × (3,000 + 90n) ≥ 20,000` → `3,000 + 90n ≥ 22,222.22…` → `90n ≥ 19,222.22…` → `n ≥ 213.58…` → `n ≥ 214`.
  - 경계 확인: `f(214) = 3,000 + 19,260 = 22,260`, `22,260 × 0.9 = 20,034 ≥ 20,000` (무료)
  - 직전값: `f(213) = 3,000 + 19,170 = 22,170`, `22,170 × 0.9 = 19,953 < 20,000` (배송비 발생)
- 구간 B의 최솟값: **214장**

**전체 최솟값**: `min(189, 214) = 189장`

## 200장 할인 경계의 함정

200장 경계에서 할인이 켜지면 오히려 무료 배송에서 멀어진다.

- `f(200) = 3,000 + 18,000 = 21,000`, 할인 뒤 `21,000 × 0.9 = 18,900 < 20,000` → **배송비 발생**.
- 반면 할인 없는 189장은 20,010원으로 **무료 배송**이다.

즉 200장을 넘겨 할인을 받는 것보다, 할인 없이 189장을 주문하는 편이 무료 배송 문턱을 먼저 넘는다. 그래서 최소 장수는 200장 이상 구간(214장)이 아니라 189장이다.

## 단위
