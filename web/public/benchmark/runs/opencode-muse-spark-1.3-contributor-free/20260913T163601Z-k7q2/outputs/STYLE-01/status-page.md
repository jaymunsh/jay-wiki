# 서비스 장애 공지 (9월 14일 결제 승인 지연)

9월 14일 14시 2분부터 15시 47분까지(KST), 총 약 105분 동안 결제 승인 요청이 지연되는 현상이 발생했습니다. 원인은 당일 배포에서 DB 커넥션 풀 크기 설정이 누락되어 풀이 고갈된 것으로 확인되었습니다. 이번 현상은 실패가 아니라 지연이었으며, 지연된 결제 승인 312건은 전부 정상 처리되었습니다. 중복 결제 0건, 오청구 0건을 확인했습니다. 현재 서비스는 정상 동작 중입니다. 재발 방지를 위해 풀 크기 항목을 배포 체크리스트에 추가했습니다. 이용에 불편을 드려 죄송합니다.
