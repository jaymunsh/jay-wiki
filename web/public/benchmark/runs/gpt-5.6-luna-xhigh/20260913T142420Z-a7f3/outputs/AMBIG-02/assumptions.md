# AMBIG-02 판단 근거

- **시도 횟수:** 명세가 상한을 주지 않으므로 무한 재시도를 피하기 위해 최초
  호출을 포함한 최대 3회로 정했다. 이는 정책의 사실이 아니라 이 구현의
  안전한 기본값이며, 운영 정책으로 확정하려면 호출자 요구가 필요하다.
- **실패의 범위:** 동기적으로 던진 예외와 Promise rejection을 모두 외부 API
  실패로 취급한다. `await fn()`이 두 형태를 같은 경로로 관찰하게 한다.
- **지연:** 백오프·지연·지터가 명세에 없으므로 대기하지 않고 즉시 다음
  시도를 한다. 지연이 필요한 API라면 별도 정책 입력으로 바꿔야 한다.
- **최종 오류:** 마지막 실패의 원래 값을 그대로 다시 던진다. 오류를 문자열로
  바꾸거나 성공처럼 감추지 않는다.
- **성공과 호출 인자:** 성공한 첫 반환값을 그대로 반환하고, `fn`에는 인자를
  전달하지 않는다. 함수가 아니면 호출 전에 `TypeError`를 던진다.
