# 결제 승인 요청 지연 안내

9월 14일 14:02부터 15:47까지(KST) 결제 승인 요청이 지연되는 장애가 발생했습니다. 요청이 실패한 것은 아니며, 총 312건의 승인 요청 처리에 지연이 있었습니다.

원인은 당일 배포에서 데이터베이스 커넥션 풀 크기 설정이 누락되어 풀이 고갈된 것이었습니다. 지연된 312건은 모두 정상 처리됐고 현재 서비스는 정상 상태입니다. 재발 방지를 위해 커넥션 풀 크기 항목을 배포 체크리스트에 추가했습니다. 이용에 불편을 드려 죄송합니다.

현재까지 확인된 영향은 결제 승인 지연 312건이며, 해당 요청은 모두 정상 처리 완료됐습니다. 중복 결제와 오청구는 각각 0건으로 확인됐습니다.
