# AMBIG-01 판단 근거

- **10분 단위 반올림:** “이후 10분당”은 10분을 조금이라도 사용하면 해당
  단위를 청구하는 것으로 해석했다. 따라서 무료 30분을 뺀 시간을 `ceil(시간/
  10분)`으로 계산한다. 정확히 30분이면 0원이고 30분을 초과하면 첫 단위를
  청구한다.
- **무료 시간의 기준:** 입·출차 시각 사이의 실제 경과 시간에서 30분을 한 번
  공제한다. 날짜의 시각 부분을 따로 반올림하지 않는다.
- **1일 최대:** 명세에 “하루”가 달력일인지 24시간 구간인지 정의가 없으므로,
  한 번의 주차 체류에 적용되는 총 요금 상한 15,000원으로 정했다. 여러 날
  체류를 달력일별로 나누어 다시 계산하지 않는다.
- **시간대와 DST:** ISO 8601 오프셋이 있으면 JavaScript `Date`가 나타내는
  실제 경과 밀리초를 사용한다. 입력에 오프셋이 없을 때의 로컬 시간대 해석은
  실행 환경에 맡겨지므로, 운영자는 오프셋을 포함해 호출하는 것으로 정했다.
- **입력 관계:** 두 값이 파싱 가능한 ISO 8601 문자열이어야 하고, 출차가
  입차보다 뒤여야 한다. 이 조건을 만족하지 않으면 `RangeError`를 던진다.
