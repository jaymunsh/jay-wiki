# Python 3.12 `tomllib` 조사

조회일: 2026-09-13 (KST)

Python 3.12 공식 문서에 따르면 `tomllib`은 Python 3.11에서 표준 라이브러리에 추가됐다. TOML 1.0.0을 파싱하는 모듈이며, `tomllib.loads()`는 문자열을 읽어 사전으로 변환한다. 반면 모듈 자체에는 TOML 쓰기 기능이 없다. 따라서 “읽기와 쓰기를 모두 지원하는가?”라는 질문에는 **읽기는 지원하지만 쓰기는 지원하지 않는다**고 답해야 한다. 이미 있는 TOML의 형식을 보존하며 편집하려면 문서가 안내하는 별도 TOML Kit, 쓰기 API가 필요하면 Tomli-W 같은 외부 패키지를 검토해야 한다.

파일을 읽을 때는 `tomllib.load(fp)`를 사용한다. 공식 시그니처 설명은 `fp`가 읽을 수 있는 **바이너리 파일 객체**여야 한다고 명시한다. 문서의 예제도 `open("pyproject.toml", "rb")`로 열고 `tomllib.load(f)`를 호출한다. 텍스트 모드 `"r"`가 아니라 `"rb"`가 필요한 이유를 코드에 반영해야 한다. 문자열을 이미 가지고 있다면 파일 객체가 아니라 `tomllib.loads(toml_str)`를 사용한다.

검색 결과 요약만 본 것이 아니라 Python 3.12 공식 원문 페이지를 열어 모듈 추가 버전, 쓰기 지원 여부, `load`의 바이너리 조건, `loads`의 입력 타입과 예제를 대조했다. TOML이 유효하지 않으면 `TOMLDecodeError`가 발생한다는 예외 조건도 확인했다.
