주요 기능

작업 기록

프롬프트와 결과, 사용한 모델을 프로젝트별로 기록합니다.

결과 비교

같은 작업을 여러 모델에 실행한 결과를 표와 나란히 보기로 비교합니다.

Markdown 내보내기

비교 결과와 메모를 Markdown 문서로 내보냅니다.

사용 흐름

  1. 프로젝트를 만들고 비교할 AI 모델을 선택합니다.
  2. 같은 작업을 여러 모델에 실행해 결과를 기록합니다.
  3. 나란히 비교해 더 나은 결과를 고르고 이유를 메모합니다.
  4. 비교 기록을 Markdown으로 내보내 공유합니다.

FAQ

무료 요금제에서 프로젝트를 4개 이상 만들 수 있나요?

무료 요금제는 프로젝트 3개까지입니다. 그 이상이 필요하면 Plus 요금제를 이용하세요.

연 결제는 얼마인가요?

Plus 연 결제는 90,000원/년입니다. 월 결제는 9,000원/월입니다.
