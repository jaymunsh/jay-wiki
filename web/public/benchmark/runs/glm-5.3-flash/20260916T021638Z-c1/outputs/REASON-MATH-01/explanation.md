# REASON-MATH-01 explanation.md

요금 규칙: 첫 100장 장당 120원, 101장째부터 장당 90원. 200장 이상이면 종이 요금 전체 10% 할인. 할인 뒤 종이 요금이 20,000원 이상이면 배송 무료, 미만이면 2,500원. 반올림 없음.

## M1 — 250장 할인 전 종이 요금

100 × 120 + (250 − 100) × 90 = 12,000 + 150 × 90 = 12,000 + 13,500 = **25,500원**

## M2 — 같은 주문의 할인 뒤 종이 요금

250 ≥ 200이므로 10% 할인: 25,500 × 0.9 = **22,950원**

## M3 — 배송비 포함 최종 금액

22,950 ≥ 20,000 → 배송 무료 → **22,950원**

## M4 — 125장씩 두 주문의 총액

한 주문당 종이 요금: 100 × 120 + 25 × 90 = 12,000 + 2,250 = 14,250원
125 < 200이므로 할인 없음. 14,250 < 20,000 → 배송비 2,500원.
주문당 14,250 + 2,500 = 16,750원, 두 주문 합계 16,750 × 2 = **33,500원**

## M5 — 무료 배송이 적용되는 최소 정수 장수

n ≤ 100이면 최대 12,000원이라 무료 배송 불가. 100 < n < 200에서는 12,000 + (n − 100) × 90 ≥ 20,000 → (n − 100) × 90 ≥ 8,000 → n − 100 ≥ 88.89 → **n ≥ 189**.

경계 비교:
- n = 188: 12,000 + 88 × 90 = 19,920 < 20,000 → 배송비 2,500원 (무료 아님)
- n = 189: 12,000 + 89 × 90 = 20,010 ≥ 20,000 → 배송 무료 ✓
- n = 200 (할인 경계): (12,000 + 100 × 90) × 0.9 = 22,950 ≥ 20,000 → 무료. 200장 할인이 요금을 낮추므로 200 이상은 전부 무료지만, 최소 장수는 그 아래 구간의 189가 된다.

따라서 최소 정수 장수는 **189장**.
