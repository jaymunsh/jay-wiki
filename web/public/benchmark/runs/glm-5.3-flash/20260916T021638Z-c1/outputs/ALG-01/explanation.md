# ALG-01 explanation.md

## 알고리즘

가중 구간 스케줄링의 표준 동적 계획법을 사용했다.

1. 작업을 종료 시각 오름차순으로 정렬(입력 배열은 사본을 정렬해 보존).
2. `dp[i]` = 정렬된 앞 i개 작업에서 얻는 최대 가치.
3. i번째 작업 `[s,e,v]`에 대해, 반열린 구간 `[s,e)`이므로 "종료 시각이 s 이하인 작업들"과 동시 선택 가능. 정렬된 end 배열에서 이진탐색으로 `ends[k] <= s`를 만족하는 최대 k를 찾아 `dp[i] = max(dp[i-1], dp[k] + v)`.

이진탐색 조건을 `ends[k] <= s`로 잡은 것이 반열린 구간 핵심이다. 앞 작업의 end가 정확히 s와 같으면(`ends[k] == s`) 함께 선택 가능하고, `ends[k] > s`이면 `[s,e)`와 겹치므로 제외된다.

## 맞는 이유

`dp`는 종료 시각 순서의 최적 부분 구조를 만족한다. i번째 작업을 선택하지 않으면 `dp[i-1]`과 같고, 선택하면 end 기준 앞쪽에서 겹치지 않는 최적해 `dp[p]`에 v를 더한 값이 최선이다. 두 경우의 최댓값이 부분 문제의 정답이 된다(교환 논법: 선택하는 경우 이후 작업은 전부 p 이전에서 고르는 것이 최적).

## 시간·공간 복잡도

- 시간: 정렬 O(n log n) + 각 작업의 이진탐색 O(log n) × n = **O(n log n)**. 200,000개 입력을 자체 테스트에서 약 0.07초에 처리(run-output.txt).
- 추가 공간: 정렬 사본·ends·dp 배열 = **O(n)**.

## 직접 확인한 경계 사례

- 빈 입력 → 0
- 동일 구간 중복(`[2,4,7]`, `[2,4,9]`) → 9 (값이 큰 하나만 선택)
- 인접 구간 `[0,1)`, `[1,2)`, `[2,3)` → 3 (반열린 접점 동시 선택)
- 포함 관계(`[0,10,15]` vs `[0,4,8]+[4,10,8]`) → 16
- 입력 배열 불변(사본 정렬로 보존)
- 잘못된 입력: 범위 초과, start>=end, 음수 value, 원소 개수 오류, 배열 아님 → RangeError
