핵심 기능

흩어지는 AI 작업을 한곳에 모으고, 판단에 필요한 비교만 남깁니다.

작업 기록

프롬프트, 응답, 사용한 모델과 조건을 작업 단위로 자동 정리합니다. 나중에 같은 질문을 다시 찾아볼 수 있습니다.

결과 비교

같은 작업을 서로 다른 모델로 실행한 결과를 나란히 놓고 차이를 확인합니다. 어떤 모델이 내 작업에 맞는지 근거로 결정합니다.

Markdown 내보내기

기록과 비교 결과를 그대로 Markdown 파일로 내보냅니다. 노트 앱이나 저장소에 바로 붙여 넣을 수 있습니다.

사용 흐름

프로젝트를 만들고, 작업을 쌓고, 비교로 정리하는 세 단계입니다.

프로젝트 만들기

비교하려는 작업 주제별로 프로젝트를 엽니다. 무료 요금제는 프로젝트 3개까지 만들 수 있습니다.

작업 기록하기

여러 모델로 실행한 작업을 프로젝트에 기록합니다. 조건과 결과가 한 화면에 정리됩니다.

비교하고 내보내기

모델별 결과를 비교해 채택할 결과를 고르고, 정리본을 Markdown으로 내보냅니다.
