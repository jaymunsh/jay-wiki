# REASON-MATH-01 계산 근거

요금 규칙: 첫 100장 장당 120원, 101장째부터 장당 90원. 200장 이상이면 종이 요금 전체 10% 할인. 할인 뒤 종이 요금이 20,000원 이상이면 배송비 무료, 미만이면 2,500원. 주문별 독립 계산.

## M1 — 250장 할인 전 종이 요금

`100×120 + 150×90 = 12,000 + 13,500 = 25,500원`

## M2 — 250장 할인 뒤 종이 요금

250 ≥ 200이므로 10% 할인: `25,500 × 0.9 = 22,950원`

## M3 — 250장 최종 금액

할인 뒤 22,950 ≥ 20,000이므로 배송비 무료. `22,950 + 0 = 22,950원`

## M4 — 125장씩 두 주문

한 주문(125장): `100×120 + 25×90 = 12,000 + 2,250 = 14,250원`. 125 < 200이라 할인 없음. 14,250 < 20,000이라 배송비 2,500원 → 주문당 16,750원. 두 주문: `16,750 × 2 = 33,500원`. (분할하면 할인도 무료 배송도 놓쳐 한 번 주문 22,950원보다 비싸다.)

## M5 — 무료 배송 최소 장수: 189장

n장의 할인 전 종이 요금을 P(n) = 12,000 + 90(n−100)(n > 100)이라 하면 구간별로 나눈다.

- **n < 200(할인 없음)**: `P(n) ≥ 20,000` ⇔ `90(n−100) ≥ 8,000` ⇔ `n ≥ 188.9` → 정수 최소값 189.
  - 경계: P(188) = 12,000 + 90×88 = 19,920 < 20,000(배송비 발생), P(189) = 20,010 ≥ 20,000(무료).
- **n ≥ 200(10% 할인)**: `0.9·P(n) ≥ 20,000` ⇔ `P(n) ≥ 22,222.3` ⇔ `n ≥ 213.6` → 정수 최소값 214.
  - 경계: 200장은 할인이 적용돼 0.9×21,000 = 18,900 < 20,000으로 오히려 무료 배송을 놓친다. 0.9·P(213) = 19,953 < 20,000, 0.9·P(214) = 20,034 ≥ 20,000.

두 구간의 최소값 189 < 214이므로 전체 최소는 **189장**이다. 200장 할인 경계에서 할인이 기준액을 오히려 밑돌게 한다는 함정을 구간 분리로 확인했다.
