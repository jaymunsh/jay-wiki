# ALG-01 RESULT

## 수행

- `solution.mjs`: 종료 시각 정렬 + 이진 탐색 DP(가중 작업 선택). 입력 검증 → `RangeError`, 빈 입력 → 0, 입력 비파괴.
- `test_solution.mjs`: `node --test`로 자체 검증.
- 검증 명령: `node --test test_solution.mjs` → **9/9 통과**(공개 예시, 반열린 경계, 중복 구간, 무효 입력, 비파괴, 20만 건 약 56ms).
- 사용 도구: 파일 쓰기, 로컬 `node --test`. 외부 검색·패키지·계산 보조 없음.

## 한계·미확인

- 자체 테스트 통과이며 독립 평가 통과가 아니다(미채점).
- 20만 건 측정은 이 머신 1회 실행 값으로 다른 환경에서는 다를 수 있다.
- value 합이 안전 정수 범위라는 문제 조건을 신뢰하고 일반 Number로 합산했다.
