# ALG-01 풀이 설명

## 알고리즘

가중 작업 선택(weighted interval scheduling)의 표준 DP다.

1. 입력을 먼저 전부 검증한다(길이 3 배열, 유한 정수, `0 <= start < end <= 1e9`, `0 <= value <= 1e9`). 어느 하나라도 어긋나면 `RangeError`.
2. 작업을 종료 시각 `end` 오름차순으로 정렬한다. 입력 배열·내부 배열을 바꾸지 않기 위해 `jobs.slice()` 사본을 정렬한다.
3. 정렬된 순서에서 `p(i)` = `end <= start_i`인 마지막 작업 인덱스를 이진 탐색으로 찾는다(없으면 -1).
4. `dp[i] = max(dp[i-1], value_i + dp[p(i)])`. 마지막 `dp[n-1]`이 답이다.

## 맞는 이유

종료 시각 순 정렬 뒤 앞부분만 보면, i번째 작업을 택하면 그 앞에서 겹치지 않는 최적해가 `dp[p(i)]`로 이미 계산돼 있고, 택하지 않으면 `dp[i-1]`과 동일하다. 두 선택지의 최대가 i까지의 최적해이므로 귀납적으로 전체 최적해가 된다. 반열린 구간이므로 `end <= start`를 포함 조건으로 써서 붙어 있는 작업도 함께 선택된다.

## 복잡도

- 시간: 정렬 O(n log n) + n번의 이진 탐색 O(n log n) = O(n log n).
- 공간: 정렬 사본·ends·dp로 O(n). n=200,000을 처리한다.

## 직접 확인한 경계 사례(node:test)

- 공개 예시 4건 전부 일치.
- 붙어 있는 구간 `[0,5)`+`[5,10)` 둘 다 선택(반열린 구간).
- 같은 구간 중복 작업은 더 큰 value 선택(`[2,4,7]` vs `[2,4,9]` → 9).
- value 0 작업은 선택하지 않는 것과 같음.
- 잘못된 입력 거부: 배열 아님·길이 오류·`start>=end`·음수·상한 초과·비정수·NaN·Infinity·객체 모두 `RangeError`.
- 입력 배열·작업 배열 비파괴 확인.
- 200,000개 연속 작업 약 56ms(측정 환경: Apple Silicon Mac, Node.js 실행).
- 빈 배열 → 0. 단일 작업·전부 겹침·연쇄 구간도 개별 확인.
