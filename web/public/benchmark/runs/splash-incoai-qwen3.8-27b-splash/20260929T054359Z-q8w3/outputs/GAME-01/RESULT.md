## 구현 내용

- 10×20 보드, I·O·T·S·Z·J·L 7종, 7-bag 랜덤, NEXT 큐(5개 유지, 1개 표시).
- 이동(←/→), 시계방향 회전(↑/X, 충돌 시 취소 — 킥 없음), 소프트드롭(↓), 하드드롭(Space).
- 보조선(C/Shift): 빈 슬롯 → 현재 블록 저장 후 큐에서 다음 블록 인출(shift+리필). 슬롯 있음 → 서로 스왑, 큐 유지. 블록이 락킹된 후 한 번만 가능(`holdUsed` 플래그 — 렉시컬 클로저 상태라 키 머싱·장시간 유지·C/Shift 동시 입력으로 우회 불가). 슬롯에서 나온 블록은 기본 회전·스폰 위치로. 스포지 충돌 = 게임 오버.
- 라인 정리 1/2/3/4 → 100/300/500/800점. 드롭 자체는 무점수. 10라인마다 레벨업, 낙하 간격 800ms→730ms→…(최소 100ms).
- 일시정지(P/버튼): 중력 정지 +_hold 차단. 게임 오버 오버레이 + 재시작(R/버튼).
- 재시작: 보드·점수·라인·레벨·Hold 슬롯·락제한·큐 전체 초기화. 간격은 항상 `clearInterval` 후 1개만 `setInterval`(`syncLoop`) — 반복 재시작·레벨업에 중복 타이머 없음. 하드드롭 직후에도 1회 리암으로 레벨업 속도가 즉시 반영.
