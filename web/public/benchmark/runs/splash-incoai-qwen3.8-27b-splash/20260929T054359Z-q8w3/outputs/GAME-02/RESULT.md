## 맵 (문제 규정과 동일)

월드 2400×600, +x 오른쪽, +y 아래. 지면 윗면 y=520, 구간 [0,650]/[780,1500]/[1640,2400] (낭떠러지 [650,780]=130px, [1500,1640]=140px). 플랫폼 (350,410,160,20), (1100,400,180,20), (1800,380,180,20). 플레이어 32×44 시작 (80,476). 코인 (420,370), (1170,360), (1860,340). 적 2마리(36×36) 지면 x=900~1040, x=2000~2180 왕복. 골인 x=2310.

## 사용한 물리 수치 (기록)

| 상수 | 값 | 근거 |
|---|---|---|
| 중력 | 2000 px/s² | 최대 점프 높이 = v²/2g = 800²/4000 = 160px |
| 점프 속도 | -800 px/s | 지면→플랫폼 높이차 110/120/140px < 160px |
| 이동 속도 | 300 px/s | 공중 0.8s × 300 = 240px > 낭떠러지 130/140px |
| 밟기 바운스 | -500 px/s | 약 62px 도약 |
| 적 속도 | 120 px/s | 왕복 순회 |
| 최대 낙하 | 1000 px/s | 터널링 방지 상한 |
| 고정 스텝 | 1/60s (rAF dt 분할) | 충돌 안정성 |

점프는 **지면에서만** 엣지 트리거(공중 이중점프 불가). 플랫폼은 단단(아래면 헤드범프). 카메라 800×600 뷰포트, x를 [0, 1600]로 클램프해 플레이어 중심 추적.

## 수행한 검증 (platformer-test.mjs, 35/35 통과)

- 정적: 외부 src/href 참조 없음. 맵 상수가 문제 규정과 정확히 일치(월드/지면/플랫폼/코인/적/플레이어/골인).
- 물리: 공중 이중점프 없음, 점프 상승 153px 후 지면 복귀, 플랫폼 위에서 낙하 시 윗면(410)에 착지, 플랫폼 정면 아래에서 점프 시 아래면(430)에서 머리 정지.
- 카메라: 좌측 0 / 우측 1600 경계 클램프.
- 코인: 획득 + **중복 획득 없음**(120프레임 유지해도 1개).
- 적: 위에서 밟기 → 적 소멸 + 바운스(실패 아님) / 옆 충돌 → 실패.
- 낭떠러지: x=680에서 21프레임(≈0.35s) 후 y>600 → 실패.
- 골인: 클리어 표시 + **진행 시간 정지**(추가 스텝에도 time 불변).
- 재시작: 위치·속도·코인·적·시간·카메라·상태 전체 초기화.
- **완주 시뮬레이션(헤드리스 오토플레이어)**: 항상 우측 진행, 낭떠러지·적 접근 시 점프, 코인 플랫폼 정렬 시 점프하는 결정적 봇이 골인 도달 — **7.38초 클리어, 코인 2/3, 밟기 1회**. 동일한 입력 시퀀스로 재실행해도 결과 동일(결정적). 재시작-재시도 루프에서도 1회 만에 클리어.
- UI(rAF 스팼 스텁): 초기 1개 rAF 체인, 프레임 진행·반복 재시작에도 1개 유지(루프 중복 없음), 키 입력으로 이동, R 재시작, 클리어/실패 오버레이, HUD(코인·시간) 갱신.

## 완주 검증에 대한 성실한 고지

- 브라우저 자동화 도구가 없어 **실제 브라우저에서 완주 플레이를 수행하지 못했다**. 위 "완주"는 Node vm에서 코어 물리 엔진을 헤드리스 시뮬레이션한 오토플레이어 결과로, 맵이 완주**가능**함을 검증한 것이다. 문제 규정에 따라 "브라우저로 완주했다"고 기재하지 않는다.
- Canvas 2D는 no-op 스텁, rAF는 스팼, 키 입력은 keydown 핸들러 직접 호출로 검증했다.
