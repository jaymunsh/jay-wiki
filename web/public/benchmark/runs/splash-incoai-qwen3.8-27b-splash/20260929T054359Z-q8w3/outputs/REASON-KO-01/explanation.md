# REASON-KO-01 — 판단 근거

- **K1 (supported)** — [P1]: "개인 열람석은 회원과 비회원 모두 예약 없이 사용할 수 있다." 비회원 무예약 사용은 지문이 직접 뒷받침.

- **K2 (contradicted)** — [P2]: "이용일 전날 오후 6시**까지** 취소하면 불이익이 없다. **이 시각 이후** 취소하면 … 제한". "6시 정각"은 "6시까지"(경계 포함)에 해당하므로 불이익 없음. "정각 취소 시 제한된다"는 주장과 충돌 → contradicted. (핵심 함정: "까지" vs "이후"의 경계)

- **K3 (contradicted)** — [P2]: 예약자 본인 취소(6시 이후/불출석)는 제한하지만, "**폭우로 자료실이 이용을 취소한 경우에는 제한하지 않는다**". "취소 이유가 무엇이든 제한"이라 한 주장과 충돌 → contradicted.

- **K4 (not_established)** — [P3]: 운영팀이 "방문 증가가 개편**만의** 효과인지는 **아직 판단할 수 없다**"고 했고, 같은 달 주변 자료실 두 곳이 공사로 휴관. "원인은 개편 하나뿐이었다"는 확정 주장은 아직 확정되지 않음(반박도 아님) → not_established. (사실에 반하는 주장과 "아직 정해지지 않은" 주장 구분)

- **K5 (contradicted)** — [P4]: 검토 안은 "**금요일 개인 열람석**을 두 시간 연장"이고, "**단체실 운영 시간은 이번 검토에 포함되지 않는다**". "단체실도 연장된다"는 주장과 직접 충돌 → contradicted. (아울러 시행 여부는 결정 전이나, 단체실 배제는 지문이 명시)

## 구분 원칙
- **supported**: 지문이 해당 사실을 직접 명시.
- **contradicted**: 지문이 해당 주장에 **반하는** 내용을 명시 (K2 경계, K3 폭우 예외, K4는 아님, K5 단체실 배제).
- **not_established**: 지문이 확정도 반박도 하지 않고 **미정/판단 불가**라고만 한 경우 (K4).
