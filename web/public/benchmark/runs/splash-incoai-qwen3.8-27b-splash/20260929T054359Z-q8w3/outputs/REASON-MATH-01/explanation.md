# REASON-MATH-01 — 계산

**요율 규칙**: 첫 100장 = 120원/장, 101장부터 = 90원/장. 200장 이상 = 종이 요금 10% 할인. 배송비 = (할인 후 종이 ≥ 20,000원 → 0) / (미만 → 2,500원). 반올림 없음, 주문별 독립.

장수 `n`에 대한 종이 요금:
- `n ≤ 100`: `P = 120n` (할인 없음)
- `100 < n < 200`: `P = 12000 + 90(n-100) = 90n + 3000` (할인 없음)
- `n ≥ 200`: `P = 90n + 3000`, 할인 후 `D = 0.9(90n+3000) = 81n + 2700`

## M1 — 250장, 할인 전
`P = 100×120 + 150×90 = 12000 + 13500 = ` **25500**

## M2 — 250장, 할인 후
250 ≥ 200 → 10% 할인. `D = 25500 × 0.9 = ` **22950**

## M3 — 250장, 최종(배송비 포함)
할인 후 `22950 ≥ 20000` → 무료배송(0). `최종 = 22950 + 0 = ` **22950**

## M4 — 125장씩 2주문, 총액
주문당(125 < 200, 할인 없음): `P = 100×120 + 25×90 = 12000 + 2250 = 14250`.
`14250 < 20000` → 배송비 2500. 주문당 `14250 + 2500 = 16750`.
두 주문: `16750 × 2 = ` **33500**

## M5 — 무료배송 최소 정수 장수 = **189**

무료배송 필요조건: **할인 후** 종이 `D ≥ 20000`. 구간별:

- `n ≤ 100`: `D = 120n`, 최대 `12000 < 20000` → 불가.
- `100 < n < 200`: `D = 90n + 3000 ≥ 20000` ⟺ `90n ≥ 17000` ⟺ `n ≥ 188.89…` ⟺ **n ≥ 189**.
  - `n=189`: `D = 90·189 + 3000 = 17010 + 3000 = 20010 ≥ 20000` ✓ 무료
  - `n=188`: `D = 90·188 + 3000 = 16920 + 3000 = 19920 < 20000` ✗ (2500원)
- `n ≥ 200` (할인 경계): `D = 81n + 2700`.
  - `n=200`: `D = 0.9·(90·200+3000) = 0.9·21000 = 18900 < 20000` ✗ (할인이 오히려 20,000 아래로 낮춤)
  - `n=213`: `D = 81·213 + 2700 = 17253 + 2700 = 19953 < 20000` ✗
  - `n=214`: `D = 81·214 + 2700 = 17334 + 2700 = 20034 ≥ 20000` ✓ 무료

**200장 경계의 함정**: 200장이 되는 순간 10% 할인이 적용돼 종이 요금이 18,900원으로 떨어져 무료배송 **아니고**, 200~213장은 모두 배송비 2,500원이 붙는다. 그러나 무료배송 구간은 이미 **189~199장**에서 시작하므로, **최소** 무료 장수는 **189장**이다. (214장 이상도 무료지만 최솟값은 189.)
