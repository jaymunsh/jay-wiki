# 서비스 장애 공지

9월 14일 14:02부터 15:47까지(약 105분) 결제 승인 요청이 지연되는 장애가 발생했습니다.

원인은 당일 배포에서 데이터베이스 커넥션 풀 크기 설정이 누락되어 커넥션 풀이 고갈된 것입니다. 이 영향으로 결제 승인 요청 312건이 지연되었습니다.

다행히 중복 결제나 오청구는 발생하지 않았습니다. 지연된 312건은 모두 정상 처리를 완료했습니다.

해당 시간대에 결제가 지연되어 불편을 드린 고객분께 죄송합니다. 현재 서비스는 정상적으로 운영되고 있습니다. 재발을 방지하기 위해 커넥션 풀 크기 항목을 배포 체크리스트에 추가했습니다.
