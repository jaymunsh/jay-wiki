# AMBIG-01 판단 기록 — 주차 요금 함수

명세는 다음 세 줄과 "잘못된 입력은 RangeError" 한 줄이 전부였다.

> - 기본 30분 무료
> - 이후 10분당 500원
> - 1일 최대 15,000원

이 네 줄로 정해지지 않는 지점이 여럿 있었다. 아래에 **무엇을 어떻게 정했는지와 그 근거**를 적는다. 명세를 그대로 따르는 부분은 다시 설명하지 않는다.

---

## A. 명세가 비워 둔 지점과 내 결정

### A-1. 무료 30분은 "이용 1회당 1번"인가, "매일 30분"인가

**결정**: 이용 1회당 1번, 입차 직후에 소진한다.

**근거**: 문구가 "기본 30분 무료"다. "기본"은 요금 산정의 출발점을 뜻하므로 주차 건당 한 번 주어지는 것으로 읽었다. 여러 날 주차할 때 매일 30분씩 다시 주는 해석도 가능하지만, 그렇게 하려면 명세에 "1일 30분 무료"라고 쓰였어야 한다. 재량으로 무료 시간을 늘리는 쪽은 요금을 낮추는 방향의 해석이라 더 신중해야 한다고 봤다.

**영향**: 24시간 30분 주차에서 두 번째 날의 30분은 무료가 아니므로 1,500원이 붙는다(아래 D-3 참조).

### A-2. "10분당 500원"은 시작한 블록마다인가, 채운 블록마다인가

**결정**: 시작한 10분 블록마다(올림) 부과한다.

**근거**: 주차 요금에서 "10분당"은 통상 시작한 단위 시간에 대해 과금한다. 내림으로 하면 9분만 초과해도 무료가 되어, 40분과 39분의 요금이 같아진다. 이는 "이후 …당"이라는 문구의 의도와 어긋난다.

**경계 확인**:
- 30분 1초 → 초과 1초 → 1블록 → 500원
- 40분 → 초과 10분 → 1블록 → 500원
- 40분 1초 → 초과 10분 1초 → 2블록 → 1,000원

### A-3. 30분 미만은 0원인가

**결정**: 0원. 초과분이 0이면 블록 수도 0이다.

**근거**: "기본 30분 무료"의 직접적인 결과다. 별도 판단이 필요 없다고 봤다.

### A-4. "1일"은 달력 날짜인가, 24시간인가

**결정**: **입차 시각부터 기산하는 24시간 구간**이다.

**근거**: 달력 날짜(자정 기준)로 하면 같은 25시간 주차라도 09:00에 들어오면 이틀에 걸쳐 30,000원, 23:00에 들어오면 같은 이틀이라도 요금이 달라진다. 요금이 **입차 시각의 우연한 값**에 좌우되는 것은 명세의 의도로 보기 어렵다. 입차 시각 기준 24시간이 더 예측 가능하고 고객에게 설명하기 쉽다.

**대안과 왜 버렸는지**: 자정 기준 달력 날짜는 "1일"의 사전적 의미에 더 가깝다. 그러나 이 해석은 자정을 넘기는 짧은 주차(예: 23:50 입차, 00:10 출차, 20분)에 두 날짜의 무료 30분이 각각 적용되는지 같은 새 모호함을 만든다. 모호함을 늘리지 않는 쪽을 택했다.

### A-5. 상한은 총액에 한 번인가, 하루마다인가

**결정**: **24시간 구간마다** 15,000원 상한을 적용하고, 그 합을 청구한다.

**근거**: "1일 최대 15,000원"이라고 썼다. 총액 상한이라면 "최대 15,000원"이라고만 썼을 것이다. "1일"을 붙인 이상 하루 단위 상한으로 읽는 것이 자연스럽다.

**구간별 상한을 택한 이유(중요)**: 총액에 `15,000 × 일수`로 상한을 걸면 과대 청구가 생긴다. 24시간 30분 주차를 예로 들면:

| 방식 | 계산 | 결과 |
|---|---|---|
| 구간별 상한 (내 선택) | 1일차 70,500 → 상한 15,000 / 2일차 30분 → 1,500 | **16,500원** |
| 총액 상한 `15,000 × ceil(1470/1440)` | 무상한 총액 72,000, 상한 30,000 | 30,000원 (과대) |

2일차에는 상한을 넘길 만큼의 주차가 없었는데도 상한이 얹히기 때문이다. 그래서 24시간 구간을 실제로 나눠 계산한다.

### A-6. 무료 30분은 어느 날짜 구간에 귀속되는가

**결정**: 첫 번째 24시간 구간에 전부 귀속한다.

**근거**: A-1에서 무료 30분을 이용 1회당 1번으로 정했다. 그러면 자연히 첫 구간에 들어간다. 두 번째 구간부터는 무료 시간이 0이다.

### A-7. 초 단위·밀리초 단위 입력

**결정**: 초와 소수점 이하는 버리지 않고 그대로 계산에 넣는다. 밀리초 정수 연산으로 처리한다.

**근거**: 명세는 시각의 정밀도를 제한하지 않는다. 초를 버리면 30분 0.5초가 무료가 되어 A-2의 올림 규칙과 충돌한다.

**구현상 이유**: 분 단위 실수(`(ms/60000)`)로 계산하면 부동소수 오차로 `ceil`이 한 블록 더 붙을 수 있다. 밀리초 정수로 `ceil(충전대상ms / 600000)`을 계산해 이 위험을 없앴다.

### A-8. 잘못된 입력의 범위

**결정**: 아래를 모두 `RangeError`로 처리한다.

| 입력 | 처리 |
|---|---|
| 문자열이 아님(`null`, 숫자, 객체 등) | RangeError |
| ISO 8601 형식이 아님(`2026/09/14 10:00` 등) | RangeError |
| 달력에 없는 날짜(`2026-02-30`) | RangeError |
| 시각 성분이 범위 밖(`25:00`, `10:70`) | RangeError |
| 출차 < 입차 | RangeError |
| 입차 == 출차 | **정상 처리, 0원** |

**근거**:
- **달력에 없는 날짜를 따로 막은 이유**: `Date.parse('2026-02-30T10:00:00Z')`는 예외를 던지지 않고 **3월 2일로 조용히 넘긴다**. 형식 검사만 하면 통과해 버리므로, 연·월·일을 되짚어 실제 날짜인지 확인하는 검사를 추가했다. 자체 점검에서 이 구멍을 실제로 발견해 고쳤다.
- **입차 == 출차를 허용한 이유**: 0분 주차는 무료 구간 안이므로 0원이 자연스럽다. 반면 출차 < 입차는 시간 순서가 뒤집힌 것으로 계산 자체가 성립하지 않는다. 둘을 같은 오류로 묶지 않았다.

### A-9. 시간대(offset) 처리

**결정**: 입력에 오프셋이 있으면 그대로 쓰고, 없으면 실행 환경의 로컬 시간대로 해석한다.

**근거**: 명세가 시간대를 요구하지 않았다. 요금은 **두 시각의 차이**로만 결정되므로 두 입력의 오프셋이 같으면 결과가 시간대와 무관하다. 서로 다른 오프셋이 섞이면 `Date.parse`가 절대 시각으로 정규화하므로 역시 일관되게 동작한다.

## B. 명세를 문자 그대로 따른 부분 (판단하지 않은 것)

- 요금 단위가 원 단위 정수라는 점 — 반환값이 "요금 정수(원)"이라고 명시됐다.
- 함수 이름과 시그니처 `parkingFee(entryIso, exitIso)`.
- 500원, 30분, 10분, 15,000원이라는 수치 자체.

---

## C. 검토했지만 채택하지 않은 해석

| 해석 | 채택하지 않은 이유 |
|---|---|
| 10분당 = 채운 블록만 과금(내림) | 39분과 40분이 같은 요금이 되어 "이후 …당"의 의도와 어긋난다 |
| 무료 30분을 매 24시간마다 재부여 | 명세에 "1일 30분 무료"라고 쓰이지 않았다 |
| 1일 상한을 총액에 1회 적용 | 여러 날 주차에서 요금이 비현실적으로 낮아진다 |
| 달력 날짜(자정) 기준 상한 | 요금이 입차 시각의 우연한 값에 좌우되고, 날짜별 무료 시간 문제를 새로 만든다 |
| 출차 == 입차도 RangeError | 0분 주차는 정상적인 입력으로 볼 수 있다 |

## D. 계산 예 (내 구현의 실제 출력)

| 주차 시간 | 계산 | 요금 |
|---|---|---|
| 0분 | 무료 구간 | 0원 |
| 29분 | 무료 구간 | 0원 |
| 30분 | 무료 구간 상한 | 0원 |
| 30분 1초 | 초과 1초 → 1블록 | 500원 |
| 40분 | 초과 10분 → 1블록 | 500원 |
| 40분 1초 | 초과 10분 1초 → 2블록 | 1,000원 |
| 60분 | 초과 30분 → 3블록 | 1,500원 |
| 12시간 | 초과 690분 → 69블록 = 34,500 → 상한 | 15,000원 |
| 24시간 | 초과 1,410분 → 141블록 = 70,500 → 상한 | 15,000원 |
| 24시간 30분 | 1일차 상한 15,000 + 2일차 3블록 1,500 | 16,500원 |
| 48시간 | 1일차 15,000 + 2일차 15,000 | 30,000원 |

`24시간 30분`이 이 명세에서 가장 해석이 갈리는 지점이다. A-4, A-5, A-6의 결정이 합쳐져 16,500원이 나온다.

---

## E. 이 문서의 한계

- 위 결정들은 **명세가 비워 둔 자리를 메운 것**이지, 출제자가 의도한 정답을 확인한 것이 아니다. 명세 원문 외에 어떤 참고자료도 보지 않았다.
- 요금 규정의 실제 관행(주차장 운영 실무)을 조사하지 않았다. 일반적인 관행에 대한 내 지식에 기대어 판단했다.
- A-4/A-5의 대안 해석도 방어 가능하다. 다만 각 대안이 만드는 새 모호함까지 고려해 지금의 조합을 골랐다.
