## 확인하지 못한 것

- **실제 외부 API 호출**: 하지 않았다. 명세가 금지한 실제 호출에 해당한다. 모든 점검은 가짜 `fn`으로만 했다.
- **실제 네트워크 실패 조건**: 타임아웃·연결 거부·5xx를 실제로 만들어 시험하지 않았다.
- **재시도 폭풍 완화 효과**: 지터의 이점은 알려진 원리에 근거한 것이며, 이 코드에서 실측하지 않았다.
- **동시 호출 상황**: 여러 호출이 동시에 재시도할 때의 거동을 시험하지 않았다. 래퍼는 호출 간 상태를 공유하지 않는다.
- **`AbortError` 이름의 보편성**: 관례적 이름으로 가정했다. 모든 런타임이 같은 이름을 쓰는지 확인하지 않았다.
- **메모리·자원 누수**: 재시도가 길어질 때의 자원 사용을 측정하지 않았다.
- **출제자의 의도한 정책**: 재시도 횟수·간격·대상 오류는 명세에 없다. 내 선택이 유일한 정답이 아니다.
