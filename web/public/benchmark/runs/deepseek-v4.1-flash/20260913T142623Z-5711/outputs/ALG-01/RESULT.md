## 요구사항 충족 요약

| 요구사항 | 충족 | 근거 |
|---|---|---|
| `export function maxValue(jobs)` 제공 | 예 | `solution.mjs` |
| 반환값은 정수 하나(최대 가치 합) | 예 | `dp[n]` 반환 |
| 반열린 구간 `[start,end)` 양립 규칙 | 예 | `end <= start`로 양립 판정 |
| 입력 배열·내부 배열 비변경 | 예 | 값 복사 후 인덱스 배열만 정렬 |
| 빈 입력 → 0 | 예 | `n === 0` 조기 반환 |
| 잘못된 입력 → `RangeError` | 예 | 검증 15종 테스트 통과 |
| O(n log n) 이하 시간 | 예 | 정렬 + 이진 탐색 DP |
| O(n) 이하 추가 공간 | 예 | 길이 n 배열들만 사용 |
| 자체 테스트 | 예 | `test.mjs` 32개 검사 전부 통과 |

## 공개 예시 실행 결과

| 입력 | 기대 | 실제 |
|---|---|---|
| `[]` | 0 | 0 |
| `[[0,3,5],[3,5,6],[0,5,10]]` | 11 | 11 |
| `[[0,10,15],[0,4,8],[4,10,8]]` | 16 | 16 |
| `[[2,4,7],[2,4,9]]` | 9 | 9 |

## 자체 테스트 요약

- 총 검사 수: **32**, 실패: **0**
- 무작위 완전 탐색 대조: 2,000건 전부 일치
- 최대 규모 성능: n = 200,000에서 **32.4ms** (로컬 Node.js 22.22.2, `process.hrtime.bigint()` 측정)

## 측정 한계

- 위 시간은 **로컬 자체 테스트의 실행 시간**이며, 모델의 텍스트 생성 속도나 과제 전체 소요 시간과는 다른 값이다.
- 자기 점수와 합격 판정은 만들지 않았다. 별도 평가가 필요하다.
