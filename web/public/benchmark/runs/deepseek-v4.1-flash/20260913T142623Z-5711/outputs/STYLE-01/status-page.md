# 결제 승인 지연 장애 안내

9월 14일 14:02부터 15:47까지 약 105분간 결제 승인 요청 처리가 지연되었습니다. 결제가 실패한 것이 아니라 승인 응답이 평소보다 늦게 도착한 지연이었습니다.

## 원인

당일 배포 과정에서 데이터베이스 커넥션 풀 크기 설정이 누락되어 풀이 고갈된 것이 원인입니다.

## 영향

해당 시간대에 지연된 결제 승인 요청은 총 312건입니다. 중복 결제와 오청구는 각각 0건으로 확인되었습니다.

## 현재 상태

지연된 312건은 모두 정상 처리되었고 서비스는 정상 운영 중입니다. 재발 방지를 위해 커넥션 풀 크기 항목을 배포 체크리스트에 추가하였습니다.
