작업 기록

프롬프트, 사용한 모델, 결과 요약을 한 카드에 남깁니다. 나중에 같은 작업을 다시 꺼내 볼 수 있습니다.

결과 비교

같은 입력에 대한 두 모델의 출력을 나란히 놓고 확인합니다. 어떤 쪽이 이 작업에 맞는지 눈으로 판단할 수 있습니다.

Markdown 내보내기

기록과 비교 결과를 Markdown으로 내보내 개인 노트·위키·블로그 초안으로 그대로 옮깁니다.

사용 흐름

세 단계로 끝납니다. 별도 서버를 세울 필요 없이 개인 노트처럼 씁니다.

작업 기록 만들기

작업 이름을 정하고 프롬프트를 붙여 넣습니다. 모델 이름은 직접 적어도 되고 목록에서 골라도 됩니다.

결과 붙여 넣고 비교

모델별 결과를 카드에 붙여 넣으면 나란히 배치됩니다. 채택한 결과에 표시를 남깁니다.

Markdown으로 내보내기

비교 화면을 Markdown 문서로 내보냅니다. 원하는 곳에 붙여 넣어 보관하거나 공유합니다.
