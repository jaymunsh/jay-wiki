왜 LocalLLM Bench인가요?

복잡한 설정 없이, 몇 초 만에 정확한 성능 데이터를 제공합니다.

초고속 추론 테스트

토큰 생성 속도(Tokens/sec)와 지연 시간(Latency)을 정밀하게 측정하여 모델의 실시간 응답 능력을 평가합니다.

하드웨어 최적화

CUDA, ROCm, Metal 등 주요 GPU 백엔드를 자동으로 감지하고 최적의 양자화(Quantization) 설정을 제안합니다.

다양한 포맷 지원

GPTQ, AWQ, GGUF 등 주요 모델 포맷을 지원하며, JSON 및 CSV 형식으로 리포트를 내보낼 수 있습니다.
