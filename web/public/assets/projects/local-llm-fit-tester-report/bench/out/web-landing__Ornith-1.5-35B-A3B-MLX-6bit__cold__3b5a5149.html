How it works

4단계로 끝나는 평가

전문 지식이 없어도 5분 안에 정확한 벤치마크 결과를 얻을 수 있습니다.

1

모델 추가

GGUF, Safetensors 등 로컬 모델을 지정하거나 라이브러리에서 선택합니다.

2

벤치마크 선택

평가하려는 능력에 맞는 벤치마크 세트를 선택합니다.

3

실행

원클릭으로 실행하면 GPU가 최대 성능으로 동작합니다.

4

결과 분석

차트와 표로 결과를 확인하고 내보내기를 완료합니다.

Get started

명령 하나로 시작하세요

설치는 간단합니다. 터미널에서 아래 명령어를 실행하세요.

terminal 
# 설치
pip install localbench

# 모델 다운로드 후 벤치마크 실행
localbench download "llama-3.1-8b"
localbench run \
  --model llama-3.1-8b \
  --benchmarks mmlu,gsm8k,humaneval \
  --device auto \
  --output result.json
