실시간 측정

토큰 단위로 추적

412 tok/s

생성 중 실시간으로 속도, 지연, 메모리를 추적합니다. 그래프는 세션 종료 시 리포트에 자동 포함됩니다.

128개 벤치마크

MMLU, GSM8K, HumanEval, MATH, HellaSwag, ARC까지. 표준화된 시드와 고정 컨텍스트로 재현 가능.

GPU / CPU

CUDA, Metal, ROCm, CPU. 어떤 환경이든 동일한 지표로 측정.

양자화 비교

Q4, Q5, Q8, FP16. 양자화 수준별 정확도·속도·메모리 트레이드오프를 한눈에.

재현 가능

고정 시드, 고정 컨텍스트, 버전 고정. 같은 입력이면 같은 결과.

CLI · API · CI

어디서든 실행

터미널에서, 스크립트에서, CI 파이프라인에서. JSON·HTML 리포트로 자동 내보내기.

# 단일 명령으로 측정
$ bench run llama-3.1-8b --suite full
# 리포트 내보내기
$ bench report --format json,html
파이프라인

4단계,
재현 가능한 측정

모델 로딩부터 리포트 생성까지. 각 단계는 독립적으로 실행할 수 있고, 모든 산출물은 버전 고정으로 저장됩니다.

로딩 · 양자화 검증 벤치마크 실행 지표 집계 리포트 내보내기
01
로딩

모델 로드 & 검증

GGUF/SAFE_TENSORS 파일을 로드하고, 양자화 수준과 컨텍스트 길이를 검증합니다. 메모리 사용량을 사전에 추정합니다.

$ bench load llama-3.1-8b-q4.gguf --ctx 4096
02
실행

벤치마크 실행

선택한 스위트의 모든 벤치마크를 고정 시드로 실행합니다. 각 벤치마크는 독립적으로 타이밍되며, 실패 시 재시도됩니다.

$ bench run --suite full --seed 42 --gpu
03
집계

지표 집계

정확도, 속도, 지연, 메모리, 비용을 표준화된 방식으로 집계합니다. 종합 점수는 가중 평균으로 산출됩니다.

$ bench aggregate --weights acc:.5 spd:.3 mem:.2
04
내보내기

리포트 생성

JSON, HTML, CSV 형식으로 리포트를 생성합니다. CI에서 자동 비교하고, 회귀가 감지되면 알림을 보냅니다.

$ bench report --format json,html --compare last

리포트

결정할 수 있는 데이터

측정 결과는 단순 숫자가 아니라, 비교와 의사결정을 위한 구조화된 리포트로 나옵니다.

비교 리포트

모델 간 비교

여러 모델을 동일한 환경에서 측정한 결과를 나란히 비교합니다. 정확도, 속도, 메모리, 비용을 한 화면에서 확인합니다.

  • 동일 하드웨어 기준 공정한 비교
  • 양자화 수준별 트레이드오프 시각화
  • 회귀 감지 및 알림

JSON · HTML · CSV

측정 결과는 기계가 읽을 수 있는 JSON과 사람이 읽을 수 있는 HTML 리포트로 자동 생성됩니다. CI 파이프라인에 바로 연결할 수 있습니다.

  • JSON: CI/CD 자동 비교용
  • HTML: 브라우저에서 바로 열람
  • CSV: 스프레드시트 분석용
  • Markdown: 문서에 바로 삽입

궁금한 것

아니요. 벤치마크는 완전히 로컬에서 실행됩니다. 모델 파일만 로컬에 있으면 인터넷 연결 없이 측정할 수 있습니다. 모든 데이터는 로컬에 유지됩니다.

GGUF, SAFE_TENSORS, ONNX 형식을 지원합니다. llama.cpp, vLLM, Ollama에서 사용하는 모델 파일을 그대로 사용할 수 있습니다.

네. 모든 벤치마크는 고정 시드와 고정 컨텍스트로 실행되며, 모델 버전과 양자화 수준이 리포트에 기록됩니다. 같은 입력이면 같은 결과가 나옵니다.

네. JSON 리포트를 내보내고, 이전 실행 결과와 비교하여 회귀를 감지할 수 있습니다. GitHub Actions, GitLab CI, Jenkins 모두 지원합니다.

벤치마크는 MIT 라이선스로 배포됩니다. 개인, 상업, 연구 용도로 자유롭게 사용할 수 있습니다. 측정 결과는 사용자의 소유입니다.
