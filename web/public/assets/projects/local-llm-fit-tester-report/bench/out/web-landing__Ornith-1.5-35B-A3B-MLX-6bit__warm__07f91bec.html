LocalBench는 설치·실행·평가까지 모든 과정이 로컬에서 완료되는 경량 벤치마크 도구입니다. 인터넷 연결 없이도 수백 개의 벤치마크를 동시에 실행할 수 있습니다.

Features

프로덕션을 위한 벤치마크

개발자부터 연구자까지. 복잡한 설정 없이도 전문 수준의 평가를 제공합니다.

◈

원클릭 실행

모델과 벤치마크를 지정하면 자동으로 병렬로 실행됩니다. 드라이버나 서버 설정은 필요 없습니다.

⚡

고성능 추론

GGUF, EXLLAMAV2, ONNX 등 주요 런타임을 지원하며 4비트·8비트 양자화를 자동으로 최적화합니다.

◐

동시 벤치마크

MMLU, HumanEval, BBH 등 50개 이상의 벤치마크를 하나의 명령어로 동시에 실행하세요.

▤

재현 가능한 결과

모든 시드를 고정하고 실행 로그를 저장하여 언제 어디서든 동일한 결과를 재현할 수 있습니다.

◱

상세 리포트

질문별 정답률, 오답 분석, 지연 시간·토큰 속도를 포함하는 HTML 리포트를 즉시 생성합니다.

⬡

프라이버시 우선

데이터는 절대 외부로 전송되지 않습니다. 평가에 사용하는 모델·데이터도 모두 로컬에 머무릅니다.

How it works

4단계로 끝나는 평가

복잡한 파이프라인은 없습니다. 명령어를 실행하는 것만으로 충분합니다.

모델 선택

로컬 저장소의 GGUF·SAFETENSORS 모델을 지정합니다.

벤치마크 선택

평가하려는 벤치마크를 이름으로 선택합니다.

실행

GPU·CPU 부하를 자동으로 분산시켜 병렬로 평가합니다.

결과 확인

HTML 리포트와 CSV를 즉시 확인·공유합니다.
