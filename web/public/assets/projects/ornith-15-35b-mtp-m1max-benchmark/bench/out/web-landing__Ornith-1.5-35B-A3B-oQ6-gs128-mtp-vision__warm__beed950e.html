Features

로컬 LLM 평가에 필요한 모든 것

복잡한 설정은 없습니다. 설치하고 실행만 하면 됩니다.

🎯

일관된 벤치마크

MMLU, GSM8K, HumanEval 등 표준 평가 세트로 어떤 모델이든 동일한 조건에서 비교하세요.

⚡

실시간 성능 계측

토큰 생성 속도, 지연 시간, GPU/CPU 사용량을 실행 중에 실시간으로 확인합니다.

🔒

완전한 로컬 실행

모델도, 데이터도, 결과도 당신의 기기에만 남습니다. 인터넷 연결이 필요 없습니다.

🔀

모델 비교

여러 모델을 동시에 실행해 점수·속도·비용을 표와 그래프로 한눈에 비교합니다.

🧩

넓은 호환성

Ollama, LM Studio, vLLM, GGUF 등 주요 로컬 추론 엔진을 지원합니다.

📊

원클릭 리포트

생성된 결과를 Markdown, JSON, HTML로 내보내 팀과 공유하세요.

How it works

4단계로 끝나는 평가

전문 지식이 필요 없습니다.

1

모델 선택

로컬에 저장된 GGUF·모델을 지정하거나 목록에서 선택합니다.

2

벤치마크 선택

평가 목적에 맞는 벤치마크를 선택합니다.

3

실행

원하는 GPU/CPU 설정으로 한 번의 명령으로 실행합니다.

4

결과 분석

비교 리포트를 확인하고 내보냅니다.
