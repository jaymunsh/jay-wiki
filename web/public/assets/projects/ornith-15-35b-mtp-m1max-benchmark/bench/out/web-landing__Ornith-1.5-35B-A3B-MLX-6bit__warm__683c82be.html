당신의 GPU 위에서
로컬 LLM을 빠르게 측정하세요

LocalBench는 인터넷 연결 없이 로컬에서 실행되는 LLM 벤치마크 도구입니다. 수백 개의 벤치마크를 원클릭으로 실행하고, 성능·속도·비용을 한눈에 비교하세요.

⚡ 무료로 시작하기 더 알아보기 →
localbench — bash
$ localbench run --model llama3-8b --bench mmlu,helm,bmb
→ 로컬 GPU 감지: NVIDIA RTX 4090 (24GB)
→ 모델 로드: llama-3-8b-instruct (GGUF Q4_K_M)
[mmlu] 1000 questions … acc: 0.6842
[helm] 500 questions … avg_score: 0.7103
[bmb] 200 questions … score: 882.5
→ 평균 처리속도: 42.3 tokens/sec · 응답 지연: 210ms
→ 결과 저장: ./reports/2024-01-15.json
Why LocalBench

프라이버시와 속도를 모두 잡다

데이터가 한 번도 네트워크를 지나지 않습니다. 모든 평가가 당신의 기기 안에서完됩니다.

🔒

100% 오프라인

모델·데이터·실행 결과까지 로컬에서 처리됩니다. API 키도, 클라우드도 필요 없습니다.

⚡

원클릭 실행

복잡한 설정 없이 명령어 하나로 수십 개 벤치마크를 동시에 실행하고 결과를 수집하세요.

🧩

광범한 벤치마크

MMLU, HELM, BBH, MATH 등 산업 표준 벤치마크를 내장하고 있어 즉시 비교가 가능합니다.

🔌

다양한 백엔드

llama.cpp, Ollama, vLLM, Exllama2 등 주요 로컬 서버와 호환되어 유연하게 사용할 수 있습니다.

📊

다크 대시보드

실행 결과를 깔끔한 다크 UI의 대시보드로 시각화하고 CSV·JSON으로 내보낼 수 있습니다.

🔀

모델 비교

여러 모델을 동시에 실행하여 성능·속도·메모리 사용량을 나란히 비교하는 표를 생성하세요.

How it works

3단계로 끝나는 평가

전문가도 5분이면 첫 결과를 얻을 수 있습니다.

모델 연결

로컬에서 실행 중인 LLM 서버를 포트 또는 파일 경로로 지정하세요.

벤치마크 선택

평가하려는 능력을 가진 벤치마크를 원하는 만큼 선택하세요.

결과 분석

실행이 완료되면 점수·속도·비용 정보를 대시보드에서 확인하세요.
