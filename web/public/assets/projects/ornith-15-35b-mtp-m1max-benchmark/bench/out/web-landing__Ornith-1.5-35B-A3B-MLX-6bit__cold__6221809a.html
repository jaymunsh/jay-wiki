Core Features

로컬 LLM 평가에 필요한 모든 것

데이터를 외부로 내보내지 않으면서, 전문가 수준의 벤치마크를 실행할 수 있습니다.

⚡

최적화된 추론 엔진

GGUF / quantized 모델을 위해 특수 최적화되어 GPU와 CPU 모두에서 빠르게 벤치마크를 실행합니다.

📊

표준 벤치마크 내장

MMLU, HellaSwag, TruthfulQA, GSM8K 등 업계 표준 평가 세트를 바로 사용할 수 있습니다.

🔒

완전한 온프레미스

평가 데이터와 모델이 당신의 네트워크를 벗어납니다. 보안 감사도 걱정 없습니다.

🧩

커스텀 벤치마크

JSON/CSV로 나만의 평가셋을 정의하고 조직에 맞는 지표를 만들어 보세요.

📈

상세 리포트

카테고리별 점수, 응답 속도, 토큰 처리량을 시각화하여 비교 가능한 리포트를 생성합니다.

🔀

배타적 비교

여러 모델을 동시에 실행하여 동점수 표로 한눈에 성능 차이를 확인하세요.

How It Works

4단계로 끝나는 평가

복잡한 설정 없이 명령 하나로 로컬 모델을 검증하세요.

STEP 01

모델 로드

로컬 디스크의 GGUF 또는 로컬 서버로 실행 중인 모델을 지정합니다.

STEP 02

벤치마크 선택

평가할 지표와 샘플 수, 파라미터를 설정합니다.

STEP 03

자동 실행

로컬 하드웨어에서 자동으로 응답을 생성하고 채점합니다.

STEP 04

결과 분석

상세 리포트와 비교표를 통해 최적의 모델을 선택하세요.
