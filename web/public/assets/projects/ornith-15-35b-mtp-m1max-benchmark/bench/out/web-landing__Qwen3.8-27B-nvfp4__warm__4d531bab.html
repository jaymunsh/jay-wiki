# 로컬 LLM 벤치마크 — 재현 가능한 실행
from localeval import Runner, Suite

runner = Runner(
    model="qwen2.5-7b-instruct",
    backend="llama.cpp",
    quant="Q4_K_M",
    context=8192,
    seed=42,
)

# 지식 · 코드 · 수학 · 지시 따르기
suite = Suite("full")   # MMLU, HumanEval, GSM8K, MATH, IFEval…

result = runner.run(suite)
result.report("html", "out/")
result.save_baseline("ci")   # 회귀 감지용

print(result.summary())

궁금한 것

네. 모델 로딩부터 채점, 리포트 생성까지 전부 로컬에서 처리됩니다. 벤치마크 문항 데이터만 최초 1회 로컬에 캐시되며, 이후 실행은 오프라인으로 동작합니다. air-gapped 환경에도 배포할 수 있습니다.

GGUF와 safetensors 형식의 오픈 웨이트 모델을 지원합니다. Llama, Qwen, Gemma, Mistral, Phi, Gemma-2 등 40개 이상 모델을 기본 프로필로 제공하며, 커스텀 모델은 경로를 지정해 바로 실행할 수 있습니다.

가능합니다. FP16, Q8_0, Q4_K_M 등 양자화 수준을 지정해 실행하고, 정밀도 손실과 속도 이득을 나란히 비교합니다. 같은 모델의 여러 양자화를 한 실행에서 비교할 수도 있습니다.

네. JSON 출력을 파서로 받아 베이스라인과 비교하고, 임계값을 넘으면 빌드를 실패시키는 게이트를 제공합니다. GitHub Actions, GitLab CI, Jenkins 모두에서 동작합니다.

재현 가능성이 기본 설계입니다. 시드, 샘플링 파라미터, 컨텍스트 길이, 하드웨어를 고정하고 실행 메타데이터를 리포트에 기록합니다. 같은 조건이면 같은 결과가 나옵니다.
