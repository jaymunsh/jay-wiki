LocalBench

당신의 로컬 하드웨어에서 돌아가는 LLM의 진정한 한계를 측정하십시오.

시작하기

Core Features

Latency Analysis

TTFT(Time To First Token)부터 TPS(Tokens Per Second)까지, 추론 속도의 모든 지표를 정밀하게 분석합니다.

VRAM Profiling

모델 로드 시의 메모리 점유율과 컨텍스트 확장 시의 VRAM 변화량을 실시간으로 모니터링합니다.

Multi-Backend

llama.cpp, ExLlamaV2, AutoGPTQ 등 다양한 백엔드 엔진의 성능을 동일 선상에서 비교합니다.

Quick Start

단 한 줄의 명령어로 벤치마크 환경을 구축하세요.

# Install LocalBench via Python
pip install localbench-tool

# Run benchmark on Llama-3-8B
localbench run --model llama3-8b --quantization q4_k_m
