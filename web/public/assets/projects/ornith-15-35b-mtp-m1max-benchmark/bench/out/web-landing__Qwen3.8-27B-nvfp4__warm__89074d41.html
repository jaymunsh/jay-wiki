클라우드 불필요

모든 데이터셋을 로컬에 캐시하고, 네트워크 없이 실행합니다. 민감한 프롬프트가 외부로 나가지 않습니다.

재현 가능

시드 고정

seed, temperature, ctx를 고정해 같은 환경에서 동일한 결과를 재현합니다. CI에 붙여 회귀를 잡습니다.

리포트

JSON · HTML · CSV

결과를 JSON으로 내보내고, 비교 리포트는 HTML로 렌더링합니다. 팀에 공유하거나 아카이브로 저장하세요.

03 · 파이프라인

실행 흐름

모델 로딩부터 리포트 생성까지, 모든 단계가 로컬에서 순차적으로 처리됩니다.

01

모델 로딩

GGUF · safetensors를 로컬에서 로드하고 양자화를 적용합니다.

02

웜업

3회 워밍업으로 캐시와 커널 컴파일을 안정화합니다.

03

벤치마크 실행

선택한 스위트를 시드 고정으로 실행하고 지연을 기록합니다.

04

정확도 평가

객관식·코드·LLM-judge로 정확도를 측정합니다.

05

리포트 생성

JSON · HTML · CSV로 내보내고 대시보드에 반영합니다.

04 · 하드웨어

어디서든 실행

GPU가 없어도, ARM Mac이든, x86 서버든 — 벤치마크는 자동 감지하고 최적화된 경로를 사용합니다.

06 · 시작하기

3줄로 실행

설치 후 바로 실행합니다. 모든 옵션은 CLI 플래그로 제어할 수 있습니다.

terminal 복사 
# 설치 (단일 바이너리)
curl -fsSL https://get.benchmark.dev | sh

# 모델 로딩 + 전체 스위트 실행
bench run llama-3.1-8b --suite full --gpu 0 --seed 42

# 양자화 비교
bench compare mistral-7b --quant Q4_K_M,Q5_K,Q8_0

# 리포트 내보내기
bench report --format json,html --out ./results

# 로컬 대시보드
bench serve --port 8080
07 · FAQ

자주 묻는 질문

아니요. 모든 데이터셋을 로컬에 캐시하고, 추론과 평가까지 전부 로컬에서 실행됩니다. 네트워크 연결 없이도 동작하며, 민감한 프롬프트가 외부로 전송되지 않습니다.

가능합니다. CPU 백엔드(AVX2/AVX-512)를 자동 감지해 실행합니다. 속도는 GPU보다 느리지만, CPU 전용 벤치마크 프로파일로 정확한 비교가 가능합니다.

네. seed, temperature, context length, 양자화를 고정하면 같은 환경에서 동일한 결과를 재현할 수 있습니다. 모든 실행은 환경 메타데이터와 함께 JSON으로 기록됩니다.

가능합니다. bench run --ci 플래그로 비대화형 실행과 JSON 출력을 지원하며, 임계값 초과 시 exit code를 반환해 회귀를 자동 감지합니다.
